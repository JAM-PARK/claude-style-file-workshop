세션 ② 러닝시트

매번 달라지는 AI 결과물, 클로드 설정으로 통일해보기. 60분, 4차 모임 2026-10-01(목 예정)

한 문장: AI는 까먹는 게 아니라 애초에 못 들은 겁니다. 매번 말로 설명하는 대신 파일로 주면 둘 다 해결됩니다.

60분 흐름

시간블록장밀렸을 때 버릴 것
0~5분문제 인식1~63번만 보여주고 4~5번은 말로 한 줄
5~10분A/B 시연 (1 웹페이지 2 슬라이드)7
10~25분실습① 스타일 파일 만들기8~10예시를 그대로 쓰고 색·폰트만 바꾸게
25~35분실습② 클로드에 설정하기11메모리는 생략, 프로젝트 지식 업로드만
35~52분실습③ 결과물 만들고 새 대화에서 확인12~14새 대화 재확인은 진행자 화면으로 대신 시연
52~60분이 장표의 비밀 + 다음 단계15~16

장표 키: ← → 스페이스 이동, N 발표자 노트(경과 시간), 7번 1·2 전환, 15번 ↓↑ 줄자

신청자 맞춤 동선 (신청 결과물: 소개 웹페이지, 상세페이지)

  • 둘 다 예시 A에서 출발. 반찬 전용 줄(요일 식단표, 사진 구도, "이번 주 받아보기")만 내 내용으로 바꾸게
  • 실습①: 참고 사이트 스크린샷 + 보조 1로 초안. 자료가 없으면 보조 3(질문에 답하기)
  • 실습②: 노트북에서 배포 페이지를 열어 파일로 받기 → 프로젝트 지식에 올리기 (휴대폰에서 받으면 파일이 휴대폰에 남는다)
  • 실습③: 시작 2·3의 [ ]에 본인 내용을 넣게. 지어낸 후기·수치가 보이면 보조 2로 점검
  • 가져가기(배포 페이지 끝): 소개는 Netlify Drop 링크, 상세는 "이미지로 저장" 프롬프트. 모자라면 16번에서 숙제로
  • 현장 추가 참가자: "Claude나 ChatGPT로 문서를 만들어 보셨나요?"만 묻고 기본 트랙. Claude Code 설치·로그인이 끝난 분만 심화 탭

막혔을 때

노트북 없음옆자리와 2인 1조. 휴대폰으로 배포 페이지를 열어 예시를 고르고 입력은 짝의 노트북으로
무료 계정이라 기능이 없음프로젝트는 무료도 5개까지. 막히면 첫 메시지에 파일 첨부. 한도에 걸리면 진행자 노트북의 예시 A 프로젝트로 이어서 하고 요금제별 차이를 안내
파일이 안 올라감배포 페이지 "파일이 안 올라가면"의 첫 줄 + 파일 내용을 프로젝트 지침에 붙이고 저장
결과물이 마음에 안 듦다시 생성하지 말고 보조 2 프롬프트로 "어느 칸이 비어서 그랬는지" 같이 찾기. 이게 세션의 핵심 학습

현장 체크리스트

  • 장표·배포 페이지 오프라인 동작 확인
  • 배포 페이지 QR을 장표 8번과 인쇄물 양쪽에
  • A/B 시연 스크린샷 두 쌍 확인
  • 타이머 3개 동작 확인 (10, 11, 13번)
  • 노트북 미지참자용 인쇄물: 예시 3종 + 결과물 스크린샷
  • 진행자 계정에 예시 A로 설정된 프로젝트 만들어두기
  • 신청자 답장(만들 내용, 참고 자료, 무료·유료 계정) 확인

마무리 기록란

성공 지표: 스타일 파일을 만들었나, 실제로 설정했나, "집에서 이것도 해보고 싶다"는 구체적 대상을 말했나. 끝낸 칸에는 X를 긋는다.
