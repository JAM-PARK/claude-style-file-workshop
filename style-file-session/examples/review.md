# 템플릿과 예시 3종 검수 (승인 게이트 2)

## 세 예시 나란히 보기

| 칸 | A 골목찬장 (반찬 구독) | B 정시로 (물류 B2B) | C 새벽정밀 (품질 보고) |
| --- | --- | --- | --- |
| 대응 결과물 | 소개 웹페이지, 상세페이지 | 발표·제안 슬라이드 | 사내 문서·보고서 |
| 제목 / 본문 폰트 | Gowun Batang / Gowun Dodum | Sunflower / Nanum Gothic | Gothic A1 / Nanum Myeongjo |
| 배경 | 흰색 #FFFFFF | 연회색 #EDEEEA | 흰색 #FFFFFF |
| 강조 | 오미자 #A3294F (버튼·링크) | 지게차 노랑 #F2B705 (숫자 밑 띠만) | 불량 빨강 #A61B1B (▲ 기호와 함께만) |
| 모서리 | 버튼 6px, 나머지 0 | 전부 0 | 전부 0 |
| 배치 | 세로 긴 한 단, 요일 식단표 | 왼쪽 1/3 제목, 오른쪽 2/3 숫자 하나 | A4 한 단, 요약 3줄, 표 1개 |
| 쓰지 말 것 | 6줄 (크림·테라코타, 카드 3개, 막연한 꾸밈말 등) | 7줄 (어두운 관제실, 대시보드 카드, 파랑 등) | 7줄 (색으로만 구분, 표 머리 칠하기 등) |
| 성격 | 정갈한, 생활감 있는, 손으로 만든 | 정확한, 절제된, 숫자가 주인공인 | 읽히는, 건조한, 흑백에서도 구분되는 |

- 크림색 배경 + 세리프 제목 + 테라코타 조합: A는 제목에 세리프(Gowun Batang)를 쓰지만 배경은 흰색, 강조는 오미자색이다. "쓰지 말 것"에 크림과 테라코타를 직접 적어 막았다.
- 명도 대비: 전부 AA 이상이다.
  - A: 보조 글자 5.7, 강조 7.0
  - B: 보조 글자 6.1, 노랑 위 글자 10.3
  - C: 보조 글자 8.5, 강조 7.5
- 폰트: 모두 Google Fonts에 있다. 참가자가 claude.ai에서 결과물을 만들어도 불러올 수 있는 폰트만 골랐다.

## 11장 검수 방법으로 돌린 결과

사용자 설정이 섞이지 않은 깨끗한 Claude(빈 설정 폴더, `tools/gen-demo.sh`)로 돌렸다. 두 쪽에 같은 프롬프트를 보내고, 설정(프로젝트 지침 한 줄 + 파일)만 바꿨다. 모델은 claude-opus-5-5이다. 스크린샷은 `demo/shots/`에 있다.

| 같은 프롬프트 | 설정 없음 | A 설정 | B 설정 |
| --- | --- | --- | --- |
| 반찬 소개 웹페이지 | 크림 배경, 테라코타 둥근 버튼, Pretendard, 가운데 정렬, 이모지 카드 3개, 영문 대문자 라벨 (AI 기본값 그대로) | 흰 바탕, 왼쪽 한 단, 요일 식단표, 오미자색 버튼 하나, Gowun 폰트 | 연회색, 왼쪽 제목 + 오른쪽 표, Sunflower 제목 |
| 물류 제안 슬라이드 | 남색→파랑 그라디언트, 하늘색 강조 단어, 알약 모양 라벨, 둥근 화살표 버튼 | (A 설정) 흰 바탕, Gowun 폰트, 얇은 선 | 연회색, "38%" 큰 숫자 + 노랑 띠, 가로선 표 |
| 품질 주간 보고 | (생성 안 함) | | (C 설정) 명조 본문, 가로선 표, ▲ 기호 + 빨강, 회색 요약칸 |

**판정: 템플릿이 작동한다.**
- 같은 프롬프트라도 A 설정과 B 설정의 결과가 확연히 다르다.
- 설정한 결과물 3개가 모두 해당 예시 파일의 색 값만 썼다. 코드에서 뽑은 hex 값이 예시의 6색과 정확히 같다.

**문서 빈칸으로 드러난 곳 (다시 생성하지 않고 문서를 고칠 근거):**
- A 설정 웹페이지가 할 일 앞에 "1 2 3" 번호를, 머리글에 "골목찬장 · 동네 반찬 구독" 같은 가운뎃점 메타 문구를 붙였다. A의 "쓰지 말 것"에 둘 다 없다.
- B 설정 웹페이지가 "01 02 03" 번호를 붙였다. B의 "쓰지 말 것"에도 없다.
- 제안: 두 파일의 "쓰지 말 것"에 "순서가 아닌 내용에 붙는 번호"와 "가운뎃점으로 이은 머리글"을 한 줄씩 추가한다. 추가하면 14번 슬라이드 메시지("어긋난 건 문서의 빈칸")의 실제 사례가 된다.

## 빈칸을 채운 뒤 다시 돌린 결과 (게이트 2 승인 후)
- A·B의 "쓰지 말 것"에 두 줄을 더하고 with 결과물 5개를 다시 생성했다. 번호와 가운뎃점이 사라졌다.
- 색 값은 이번에도 예시 파일의 값만 나왔다.
- 처음 결과물은 `demo/before-fix/`에 보관했다.

## 참고
- 설정한 쪽 결과물의 수치("배차 지연 38% 감소" 등)는 AI가 지어낸 가상 수치다. 장표와 배포 페이지에서는 "가상 브랜드, 가상 수치"라고 표기한다.
