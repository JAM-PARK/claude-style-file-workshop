# 새벽정밀 품질보증팀 디자인 시스템

> 가상 브랜드: 제조사 품질팀 주간 보고
> 이 파일로 만들기 좋은 결과물: 사내 문서·보고서

## 1. 글자
본문 폰트: Nanum Myeongjo
제목 폰트: Gothic A1 (표 안의 숫자도 이 폰트)
크기 (A4 인쇄): 제목 18pt / 소제목 12pt / 본문 10.5pt / 표 9pt, 줄간격 1.6
굵기: 본문 400, 제목 700, 표 머리 700

## 2. 색
배경:      #FFFFFF
카드·면:   #F0F0F0   (맨 위 요약 3줄 칸에만)
글자:      #000000
보조 글자: #4D4D4D
강조:      #A61B1B   (불량·기준 초과 숫자에만. 반드시 굵게 + ▲ 기호와 함께)
테두리:    #000000   (표 선 0.5pt)

## 3. 여백과 모양
기본 간격: 4px (이 값의 배수만 사용)
모서리 둥글기: 버튼 0px, 카드 0px
그림자: 없음

## 4. 레이아웃
- A4 세로 한 단, 여백 20mm. 한 장을 넘기지 않는다
- 순서: 제목 줄(보고 주차, 작성자, 작성일) → 요약 3줄 → 표 1개 → 다음 할 일
- 표는 가로선만 긋는다. 숫자는 오른쪽 정렬, 글자는 왼쪽 정렬
- 흑백으로 인쇄해도 구분되어야 한다. 상태는 색이 아니라 기호(▲ 초과, − 기준 내)와 굵기로 나눈다

## 5. 쓰지 말 것
- 색으로만 구분하기 (흑백 인쇄에서 사라진다)
- 표 머리 행에 배경색 칠하기
- 원형 차트, 3D 차트, 장식용 아이콘
- 가운데 정렬 본문
- 두 줄이 넘는 요약 문장
- 빨강을 불량·기준 초과 외에 쓰기
- 회사 로고 워터마크

## 6. 성격
이런 느낌 (형용사 3개): 읽히는, 건조한, 흑백에서도 구분되는
이런 건 아님 (참고하면 안 되는 예 2개): 경영진 보고용 화려한 PPT, 신문 지면
