방금 만든 상세페이지를 이미지로 저장할 수 있게 고쳐줘.
- 사진 자리를 누르면 내 컴퓨터에서 사진을 골라 넣을 수 있게 해줘. 사진은 자리 크기에 맞추고 넘치는 부분은 잘라줘
- 오른쪽 위에 '이미지로 저장' 버튼을 두고, 누르면 페이지 전체를 가로 860px 그대로(배율 1) PNG 한 장으로 내려받게 해줘. 파일 이름은 detail.png
- 버튼과 안내 문구는 저장된 이미지에 찍히지 않게 하고, 사진을 안 넣은 자리는 지금처럼 빈 네모로 둬
- 이미지 변환은 html-to-image 라이브러리로 해줘
- 다른 디자인은 바꾸지 말고, 전체 코드를 HTML 파일 하나로 다시 줘
