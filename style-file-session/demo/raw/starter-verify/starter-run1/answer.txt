`index.html`에 버튼 하나를 네 상태로 나란히 만들었어요. 각 버튼 위에 기본, 호버, 포커스, 비활성 이름표를 붙였습니다. 화면 전체는 만들지 않았어요.

**상태별 모습**
- **기본:** 글자색(#111311) 바탕에 흰 글자, 모서리 0
- **호버:** 바탕은 그대로이고, 버튼 아래쪽 안에 강조색(#F2B705) 4px 띠가 나타납니다. 띠가 버튼 안쪽에 있어서 버튼 크기는 변하지 않아요.
- **포커스:** 키보드로 이동했을 때만 글자색 3px 외곽선이 3px 떨어져 생깁니다. 마우스로 클릭할 때는 나오지 않아요.
- **비활성:** 보조 글자색(#555A54) 바탕에 흰 글자, 커서 금지 표시. 투명도는 쓰지 않았습니다.

호버와 포커스는 원래 마우스를 올리거나 키보드로 이동해야 보여요. 그래서 비교용 버튼에는 그 모습이 늘 보이게 해 두었습니다. 기본 버튼 위에 마우스를 올리거나 Tab 키로 이동하면 실제로 바뀌는 것도 볼 수 있어요.

**디자인 시스템 점검**
전체 점검 명령은 실행 승인이 필요해서 돌리지 못했습니다. 대신 파일을 한 줄씩 직접 대조했어요.
- **색:** 디자인 시스템의 토큰 네 개(#111311, #FFFFFF, #555A54, #F2B705)만 썼습니다. 페이지 바탕은 #EDEEEA예요.
- **간격:** 버튼 안쪽 여백 16px과 32px, 이름표와 버튼 사이 16px, 버튼끼리 64px, 페이지 가장자리 64px로, 모두 8의 배수입니다.
- **글자:** 28px, 굵기 400, 줄간격 1.5로 본문 규칙과 같습니다.
- **띠와 외곽선:** 4px 띠와 3px 외곽선·띄움은 8의 배수가 아니지만, 디자인 시스템의 컴포넌트 상태 칸에 적힌 값 그대로입니다.
- 그림자, 그라디언트, 투명도는 쓰지 않았습니다.

**확인해 주실 점**
1. **버튼 글자 크기:** 디자인 시스템에 버튼 글자 크기가 따로 없어서 본문 크기(28px, 굵기 400)를 썼어요.
2. **호버 띠 위치:** "아래에 4px 띠"를 버튼 아래쪽 안에 두었습니다. 버튼 바깥 밑에 붙이는 쪽이 의도였다면 알려주세요.
