# [이름] 디자인 시스템

## 1. 글자
본문 폰트: (정확한 폰트 이름. "깔끔한 고딕" 같은 표현은 안 됨. 예: Gowun Dodum)
제목 폰트: (예: Gowun Batang)
크기: 제목 __px / 소제목 __px / 본문 __px, 줄간격 __   (예: 40 / 24 / 17, 1.7)
굵기: 본문 __, 제목 __   (예: 400 / 700)

## 2. 색
배경:      #   (예: #FFFFFF)
카드·면:   #   (예: #EEF3E8)
글자:      #   (예: #2A2723)
보조 글자: #   (예: #6B665E)
강조:      #   (버튼, 링크에만. 예: #2F6B45)
테두리:    #   (예: #D9DDD3)
("따뜻한 빨강"이 아니라 #으로 시작하는 값으로)

## 3. 여백과 모양
기본 간격: __px (이 값의 배수만 사용. 예: 8)
모서리 둥글기: 버튼 __px, 카드 __px   (예: 버튼 6, 카드 0)
그림자: (없음 / 한 단계만)

## 4. 레이아웃
(예: 가운데 정렬 큰 제목 안 씀, 카드 격자 안 씀, 왼쪽 정렬 한 단)

## 5. 쓰지 말 것   ← 가장 중요한 칸
- (예: 보라·파랑 그라디언트)
- (예: 이모지 아이콘)
- (예: 모든 곳에 큰 둥근 모서리)

## 6. 성격
이런 느낌 (형용사 3개): (예: 정갈한, 생활감 있는, 손으로 만든)
이런 건 아님 (참고하면 안 되는 예 2개): (예: 대형마트 전단지, 고급 한정식 메뉴판)
