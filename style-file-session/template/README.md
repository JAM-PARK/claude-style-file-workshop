# design-system.md를 어디에 넣나요

스타일 파일을 만들었다면, Claude가 **매번 자동으로** 읽게 설정해야 합니다.
설정해 두면 새 대화를 열 때마다 파일을 다시 붙이지 않아도 됩니다.

## 기본 트랙: Claude 웹 (claude.ai)

1. 왼쪽 메뉴의 **프로젝트**에서 새 프로젝트를 만듭니다.
2. **프로젝트 지식**에 `design-system.md`를 올립니다. 노트북에서 배포 페이지를 열고 **파일로 받기**를 누르면 이 이름으로 받아집니다. 보조 1·3으로 만든 초안이라면 그 대화에 "이 내용을 design-system.md 파일로 만들어줘"라고 보내 파일로 받습니다.
3. **프로젝트 지침**에 아래 한 줄을 붙여 넣습니다.
   ```
   모든 결과물은 프로젝트 지식의 design-system.md를 따른다. 문서에 없는 스타일은 쓰지 않는다.
   ```
4. (선택) 설정에서 **메모리**가 켜져 있는지 봅니다. 무료 계정도 기본으로 켜져 있습니다. 켜 두면 지난 대화의 맥락도 이어받습니다.

이제 이 프로젝트 안에서 새 대화를 열고, 파일을 붙이지 말고 부탁해 보세요.

**파일이 안 올라가면:** 프로젝트 지침 칸에 3번의 한 줄 대신 아래 줄을 쓰고, 그 아래에 파일 내용을 전부 붙여 넣은 뒤 저장하세요. 지침도 새 대화마다 자동으로 읽힙니다.

```
모든 결과물은 아래 디자인 시스템을 따른다. 문서에 없는 스타일은 쓰지 않는다.
```

**무료 계정이라면:** 프로젝트는 무료 계정도 쓸 수 있지만 5개까지만 만들 수 있습니다(2026-09-28 확인). 프로젝트를 더 만들 수 없으면 대화의 첫 메시지에 `design-system.md`를 첨부하고 "이 파일을 따라줘"라고 쓰세요. 설정은 아니지만 같은 효과를 냅니다. 무료 계정은 사용량이 5시간마다 초기화되고, 긴 결과물을 만들수록 빨리 찹니다. 다시 생성하기보다 문서를 고치고 한 번에 부탁하세요.

## 심화 트랙: Claude Code

1. 작업 폴더에 `docs/design-system.md`를 둡니다.
2. 폴더 맨 위의 `CLAUDE.md`에 아래를 적습니다. `CLAUDE.md`는 Claude Code가 대화를 시작할 때마다 자동으로 읽는 규칙 파일입니다.
   ```
   UI 작업 시 반드시 따른다: @docs/design-system.md
   ```
3. (선택) Figma MCP로 Figma 변수를 읽어 `design-system.md`의 색·간격 값을 채웁니다. MCP는 Claude Code가 다른 프로그램과 연결하는 통로입니다.

자세한 절차는 배포 페이지의 **심화** 탭을 보세요.
