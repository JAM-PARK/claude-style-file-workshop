# 결과물 가져가기

claude.ai에서 만든 결과물은 대화 안에 있습니다. 밖에서 쓰려면 먼저 HTML 파일로 저장합니다. 이 순서는 **노트북 브라우저에서** 이 페이지(session02-handout.vercel.app)를 열어 따라 하세요. 휴대폰에서 받으면 파일이 휴대폰에 저장됩니다.

**claude.ai의 공유 링크는 손님에게 보낼 링크로 쓰기 어렵습니다.** 2026년 9월 16일부터 대화에서 새로 만든 결과물은 링크를 여는 사람도 Claude 계정이 있어야 하고, 무료 계정은 링크 공유 자체가 안 됩니다(2026-09-30 확인).

## 1. HTML 파일로 저장하기

1. 결과물 창에 다운로드 버튼이 보이면 그걸로 받고 2단계로 갑니다. 없으면 결과물 창에서 코드를 열어 전부 복사합니다.
2. 아래 칸에 붙여 넣고 **index.html로 받기**를 누릅니다. 다운로드 폴더에 `index.html`이 생깁니다.
3. 바탕화면에 새 폴더를 하나 만들고 `index.html`을 그 폴더로 옮깁니다. 아래 순서는 모두 이 폴더로 합니다.

<!-- 배포 페이지에서는 이 자리에 코드를 붙여 넣는 칸이 나옵니다 -->

코드가 `<!doctype html>`이 아니라 `import`로 시작하면 그대로는 열리지 않습니다. 대화에 "HTML 파일 하나로 다시 줘"라고 부탁하세요.

## 2. 상세페이지: 이미지로 저장하기

스마트스토어·쿠팡 같은 판매처에는 상세페이지를 이미지로 올립니다. 이미지를 만드는 일도 Claude에게 맡깁니다.

1. 상세페이지를 만든 대화에 아래 문장을 보냅니다.
2. 새로 받은 코드를 위 "1. HTML 파일로 저장하기"처럼 `index.html`로 받아 폴더에 넣습니다.
3. 폴더의 `index.html`을 Chrome으로 엽니다. 사진 자리를 누르면 내 컴퓨터의 사진을 고를 수 있습니다.
4. 사진을 다 넣었으면 오른쪽 위 **이미지로 저장**을 누릅니다. 다운로드 폴더에 가로 860px 이미지 `detail.png`가 생깁니다.

```
방금 만든 상세페이지를 이미지로 저장할 수 있게 고쳐줘.
- 사진 자리를 누르면 내 컴퓨터에서 사진을 골라 넣을 수 있게 해줘. 사진은 자리 크기에 맞추고 넘치는 부분은 잘라줘
- 오른쪽 위에 '이미지로 저장' 버튼을 두고, 누르면 페이지 전체를 가로 860px 그대로(배율 1) PNG 한 장으로 내려받게 해줘. 파일 이름은 detail.png
- 버튼과 안내 문구는 저장된 이미지에 찍히지 않게 하고, 사진을 안 넣은 자리는 지금처럼 빈 네모로 둬
- 이미지 변환은 html-to-image 라이브러리로 해줘
- 다른 디자인은 바꾸지 말고, 전체 코드를 HTML 파일 하나로 다시 줘
```

- 이미지로 바꾸는 도구를 인터넷에서 불러오므로 인터넷이 연결된 상태에서 누릅니다.
- 대화 화면 안의 미리보기에서는 저장이 안 될 수 있습니다. 꼭 저장한 `index.html`을 Chrome에서 여세요.
- 네이버 스마트스토어 상세설명 권장 너비는 가로 860px, 이미지 한 장은 20MB까지입니다. 상세가 4000px을 넘으면 위 3000px만 먼저 보이고 나머지는 접히므로 핵심 문구와 특징을 위쪽에 둡니다(2026-09-30 확인).
- 쿠팡은 WING 등록 화면에 뜨는 크기 안내를, 와디즈는 가로 1024px 이하를 따릅니다.
- 상품정보제공고시는 상세 이미지와 별도로 등록 화면에서 입력하는 필수 항목입니다.

**사진이 위아래(또는 양옆)로 잘려 보이면** 정상입니다. 사진 자리를 빈틈없이 채우려고 넘치는 부분을 자른 것입니다. 사진 전체가 보이게 하려면 같은 대화에 아래 문장을 보내고, 새로 받은 코드로 폴더의 `index.html`을 바꿔 넣습니다. 대신 사진마다 자리 높이가 달라집니다.

```
사진을 자르지 말고 전체가 보이게 해줘. 사진 자리의 가로 너비는 그대로 두고, 높이는 넣은 사진의 비율에 맞춰 늘거나 줄게 해줘. 다른 디자인은 바꾸지 말고 전체 코드를 HTML 파일 하나로 다시 줘.
```

## 3. 소개용 웹페이지: 링크 만들기

**사진 넣기.** 대화 안에서는 내 사진을 보여 줄 수 없어서 사진 자리가 빈 네모로 나옵니다. 올리기 전에 채웁니다.

1. 사진을 같은 폴더에 넣고 사진 자리 순서대로 이름을 `photo1.jpg`, `photo2.jpg`처럼 영어 소문자로 바꿉니다. 아이폰 사진(.heic)은 브라우저에 보이지 않으니 JPG로 바꿔서 넣습니다(Mac은 미리보기의 파일 > 내보내기).
2. 결과물을 만든 대화에 아래 문장을 보내고, 새로 받은 코드를 위 "1. HTML 파일로 저장하기"처럼 `index.html`로 받아 폴더의 옛 파일을 바꿔 넣습니다.

```
사진 자리를 위에서부터 순서대로 photo1.jpg, photo2.jpg … 파일을 보여 주는 <img>로 바꿔줘. 사진은 자리 너비에 맞추고 넘치는 부분은 잘라줘. 전체 코드를 다시 줘.
```

**올리기.** 가장 쉬운 방법은 Netlify Drop입니다. 폴더를 끌어다 놓기만 하면 주소가 생깁니다.

1. [netlify.com](https://www.netlify.com)에서 무료 계정을 만들고 로그인합니다. 로그인하지 않고 올린 사이트는 1시간 안에 계정에 연결하지 않으면 잠기고, 얼마 뒤 지워집니다.
2. [app.netlify.com/drop](https://app.netlify.com/drop)을 열고 `index.html`과 사진이 든 폴더를 화면에 끌어다 놓습니다.
3. 생긴 주소를 휴대폰에서 열어 봅니다. 고친 뒤 다시 올릴 때도 같은 화면에 폴더를 다시 끌어다 놓습니다.

| 다른 방법 | 이럴 때 | 주의 |
| --- | --- | --- |
| Cloudflare Pages | 한국어 화면이 편할 때, 오래 쓸 주소 | 가입 필요. 폴더나 zip으로 올림 |
| Vercel Drop | 파일 하나만 바로 올릴 때 | 무료는 개인·비상업 용도만 |
| tiiny.host | 사진 없는 짧은 페이지 | 무료는 3MB, 페이지 하나, 배너 붙음 |
| claude.ai 공유 | Claude를 쓰는 동료에게 보여 줄 때 | 여는 사람도 Claude 계정 필요 |

## 4. 개발자에게 넘기기

같이 일하는 개발자가 있다면 링크 대신 **폴더를 통째로** 넘깁니다.

1. 폴더에 `index.html`, 사진, 스타일 파일 `design-system.md`를 함께 넣고 zip으로 압축합니다.
2. 전달 메모는 AI에게 쓰게 합니다. 결과물을 만든 대화에 아래 문장을 보내고, 받은 글을 복사해 zip과 함께 보내는 메일이나 메신저에 붙입니다.
3. 메모 맨 아래에 한 줄을 덧붙입니다. "색·글꼴·간격은 design-system.md를 기준으로 해 주시고, 바꿔야 하면 이 파일부터 고쳐 주세요."

```
이 결과물을 개발자에게 넘길 전달 메모를 써줘. 아래 항목을 표나 목록으로.
- 아직 채우지 않은 [ ] 칸과 사진 자리: 위치와 들어갈 내용
- 쓴 글꼴 이름과 불러오는 주소, 쓴 색 값 (design-system.md와 다른 값이 있으면 표시)
- 기준 화면 너비와 확인할 기기 (휴대폰, 노트북)
- 아직 동작하지 않는 것 (버튼, 문의 양식, 링크)
- 이 결과물을 만들 때 쓴 부탁 문장
```
