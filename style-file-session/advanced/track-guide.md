# 심화 트랙 실습 지시문

심화 트랙도 기본 트랙과 같은 60분 흐름을 따릅니다. 다만 스타일 파일을 **코드에서 쓰는 토큰**으로 다루고, 설정은 **CLAUDE.md**로, 검증은 **컴포넌트 상태와 코드에 쓰인 값** 단위로 합니다.

| 블록 | 기본 트랙 | 심화 트랙 |
| --- | --- | --- |
| 실습① 15분 | 예시를 골라 내 값으로 바꾸기 | 가진 자료에서 토큰을 추출해 design-system.md 작성 |
| 실습② 10분 | 프로젝트 지식 + 지침 한 줄 | CLAUDE.md에서 불러오기 + 설정 확인 |
| 실습③ 17분 | 4종 중 택 1 → 새 대화에서 재확인 | 버튼 상태 확인 → 화면 1개 → `/clear` 후 재요청 → 값 대조 → (여유 시) Figma로 보내기 |

## 실습① 스타일 파일을 토큰으로 만들기

1. 가진 자료에 따라 출발점을 고릅니다.
   - Figma 파일에 변수(Variables)가 있다 → Figma MCP로 읽기
   - 운영 중인 사이트나 코드가 있다 → Claude Code에게 CSS에서 값 뽑게 하기
   - 스크린샷뿐이다 → 기본 트랙 보조 1 프롬프트로 초안 만든 뒤 아래 7~8칸 추가
2. 기본 템플릿 6칸에 심화용 7~8칸(아래)을 더합니다.
3. 한 번만 쓰인 값은 토큰으로 넣지 않고 따로 모아 본인이 판단합니다.

## 심화용 추가 칸 (기본 템플릿 6칸 뒤에 붙인다)

```
## 7. 토큰 (코드용)
:root {
  --color-bg: #;
  --color-surface: #;
  --color-text: #;
  --color-text-muted: #;
  --color-accent: #;
  --color-border: #;
  --space-1: 4px;          /* 기본 간격. 나머지는 이 값의 배수 */
  --radius-button: px;
  --radius-card: px;
}
토큰 이름 규칙: --종류-역할 (예: --color-accent)
값을 드러내는 이름(--blue-500)은 쓰지 않는다

## 8. 컴포넌트 상태
버튼: 기본 / 호버 / 포커스(키보드) / 비활성 각각 무엇이 달라지는지
입력창: 기본 / 포커스 / 오류 / 비활성
```

## 실습② CLAUDE.md로 설정하기

1. 스타터 폴더를 만듭니다. 아래 "스타터 만들기" 프롬프트로 Claude Code가 직접 만듭니다.
2. `CLAUDE.md`가 `@docs/design-system.md`를 불러오는지 확인합니다.
3. "설정 확인" 프롬프트로 Claude Code가 규칙을 읽었는지 확인합니다.

## 실습③ 결과물 만들고 검증하기

1. 버튼 하나를 네 가지 상태(기본, 호버, 포커스, 비활성)로만 먼저 만듭니다. 화면 전체는 아직 만들지 않습니다.
2. 통과하면 같은 규칙으로 결과물 1개를 만듭니다 (공지 4종 중 택 1).
3. `/clear`로 대화를 비우고 같은 요청을 다시 보냅니다. CLAUDE.md 덕분에 같은 규칙이 적용되면 성공입니다.
4. "값 대조" 프롬프트로 코드에 쓰인 색·px 값 중 디자인 시스템에 없는 것을 찾습니다. 기본 트랙의 "문서 빈칸 고치기"를 코드 수준에서 하는 단계입니다.
5. 여유가 있으면 로컬 화면을 Figma 레이어로 보냅니다.
