# 심화 트랙: Claude Code 프롬프트

선수조건: Claude Code를 설치하고 로그인을 마친 상태여야 합니다.
`[ ]` 안은 내 내용으로 바꿔 넣으세요.

| 블록 | 순서 |
| --- | --- |
| 실습① 15분 | 스타터 만들기 → 토큰 추출(Figma 또는 코드) |
| 실습② 10분 | 설정 확인 |
| 실습③ 17분 | 버튼 상태 확인 → 결과물 만들기 → `/clear` → 같은 요청 → 값 대조 → (여유 시) Figma로 보내기 |

## 스타터 만들기

```
아래 두 파일을 이 폴더에 만들어줘. 경로는 그대로 지켜.
빈 index.html도 하나 만들어줘.

[CLAUDE.md 내용 붙여넣기]
[docs/design-system.md 내용 붙여넣기]
```

## 토큰 추출: Figma 파일에서

```
연결된 Figma 파일 [링크]의 변수와 텍스트 스타일을 읽어서
docs/design-system.md의 칸을 채워줘.
Figma에 없는 값은 비워두고 (없음)이라고 표시해.
'쓰지 말 것' 칸은 제안만 하고 확정은 내가 할게.
```

## 토큰 추출: 코드에서

```
이 폴더의 CSS에서 실제로 쓰이는 색, 폰트, 간격, 둥글기 값을 모두 뽑아
자주 쓰이는 순서로 정리하고 docs/design-system.md 초안을 만들어줘.
한 번만 쓰인 값은 따로 모아서 보여줘. 토큰으로 넣을지는 내가 정할게.
```

## 설정 확인

```
지금 따르고 있는 디자인 규칙을 5줄로 요약해줘. 어느 파일에서 읽었는지도 알려줘.
```

## 버튼 상태 확인

```
docs/design-system.md의 값만 써서 버튼 하나를 기본, 호버, 포커스, 비활성 네 상태로 index.html에 만들어줘.
화면 전체는 아직 만들지 마.
```

## 결과물 만들기

```
버튼이 괜찮으니 같은 규칙으로 [발표 슬라이드 / 소개 웹페이지 / 상세페이지 / 사내 보고서] 하나를 index.html에 만들어줘.
```

## 값 대조

`/clear`로 대화를 비우고 같은 요청을 한 번 더 보낸 뒤에 씁니다.

```
index.html에 쓰인 모든 색 값과 px 값을 뽑아서 docs/design-system.md와 대조해줘.
디자인 시스템에 없는 값을 목록으로 보여주고, 각각 디자인 시스템에 추가할지 코드에서 바꿀지 제안해줘.
```

## Figma로 보내기

```
로컬에서 띄운 index.html 화면을 Figma 파일 [링크]에 편집 가능한 레이어로 보내줘.
```
