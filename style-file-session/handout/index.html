스타일 파일이 뭔가요

스타일 파일(design-system.md)은 내 결과물이 어떻게 생겨야 하는지 적어 둔 한 장짜리 메모입니다. 글자, 색, 여백, 배치, 쓰지 말 것, 성격 여섯 칸이면 됩니다.

왜 필요한가요

  • AI는 평균을 만듭니다. AI는 가장 그럴듯한 답을 고르고, 디자인에서 가장 그럴듯한 답은 수많은 템플릿의 평균입니다. 그래서 따로 말하지 않으면 누가 부탁해도 가운데 큰 제목, 파란 버튼, 똑같은 카드 3개가 나옵니다.
  • 대화는 매번 새로 시작합니다. 어제 대화에서 "이 색으로 해줘"라고 한 말은 오늘 새 대화로 넘어오지 않습니다. 그래서 같은 부탁을 해도 매번 다르게 나옵니다.
  • 파일은 남습니다. 스타일을 파일 한 장에 적어 프로젝트에 넣어 두면 새 대화를 열 때마다 Claude가 알아서 읽습니다. 매번 설명하지 않아도 같은 스타일로 나오고, 같은 파일을 동료나 개발자에게 건네면 그 사람도 같은 기준으로 작업합니다.

있을 때와 없을 때

같은 부탁("반찬 구독 서비스 소개 웹페이지 한 장을 만들어줘")을 두 번 보냈습니다. 다른 점은 스타일 파일(예시 A)을 설정했는지 하나뿐입니다.

파일 없이예시 A 파일을 설정하고
배경과 강조색크림색 배경, 주황 둥근 버튼흰 바탕, 오미자색 버튼 하나
글꼴AI가 자주 고르는 Pretendard파일에 적은 Gowun Batang, Gowun Dodum
배치가운데 정렬 큰 제목, 이모지 카드 3개왼쪽 정렬 한 단, 요일 식단표
새 대화에서 다시 부탁하면앞 대화의 스타일을 모름파일을 다시 읽어 같은 색 값으로

디자인을 몰라도 만드는 법

처음부터 잘 쓰려고 하지 않아도 됩니다. 한 번 만들어 보고, 마음에 안 드는 곳을 한 줄씩 고쳐 가는 파일입니다.

  1. 백지에서 시작하지 않습니다. 아래 예시 3종 가운데 내 결과물과 가까운 것을 복사해 이름, 색, 글꼴만 바꿉니다. 소개 웹페이지와 상세페이지는 예시 A가 가깝습니다.
  2. 참고 자료가 있으면 AI에게 뽑게 합니다. 좋아하는 사이트나 우리 가게 전단을 캡처해 대화에 올리고 보조 1 프롬프트를 보냅니다. 색 값과 글꼴 이름을 몰라도 AI가 채워 줍니다.
  3. 참고 자료가 없으면 질문에 답합니다. 보조 3 프롬프트를 보내면 Claude가 보기를 주며 질문을 하나씩 합니다. 번호만 골라도 파일이 완성됩니다.
  4. 모호한 말 대신 이름과 값을 씁니다. "깔끔한 고딕"이 아니라 글꼴 이름(예: Gowun Dodum), "따뜻한 빨강"이 아니라 #A3294F처럼 씁니다. 모르면 AI에게 "이 느낌에 맞는 Google Fonts 한글 글꼴 3개와 색 값을 골라줘"라고 물어보세요.
  5. "쓰지 말 것"은 결과를 보고 채웁니다. 가장 쉽게 채우는 방법입니다. 한 번 만들어 보고 싫은 것(이모지, 그림자, 카드 나열 같은 것)을 그대로 적습니다. 비워 두면 AI가 기본값으로 채웁니다.
  6. 고칠 때마다 한 줄 남깁니다. 결과가 어긋나면 다시 생성하지 말고 파일을 고친 뒤 "변경 기록"에 날짜와 이유를 적습니다. 파일이 점점 내 것이 됩니다.

2. 상세페이지: 이미지로 저장하기

스마트스토어·쿠팡 같은 판매처에는 상세페이지를 이미지로 올립니다. 이미지를 만드는 일도 Claude에게 맡깁니다.

  1. 상세페이지를 만든 대화에 아래 문장을 보냅니다.
  2. 새로 받은 코드를 위 "1. HTML 파일로 저장하기"처럼 index.html로 받아 폴더에 넣습니다.
  3. 폴더의 index.html을 Chrome으로 엽니다. 사진 자리를 누르면 내 컴퓨터의 사진을 고를 수 있습니다.
  4. 사진을 다 넣었으면 오른쪽 위 이미지로 저장을 누릅니다. 다운로드 폴더에 가로 860px 이미지 detail.png가 생깁니다.
방금 만든 상세페이지를 이미지로 저장할 수 있게 고쳐줘.
- 사진 자리를 누르면 내 컴퓨터에서 사진을 골라 넣을 수 있게 해줘. 사진은 자리 크기에 맞추고 넘치는 부분은 잘라줘
- 오른쪽 위에 '이미지로 저장' 버튼을 두고, 누르면 페이지 전체를 가로 860px 그대로(배율 1) PNG 한 장으로 내려받게 해줘. 파일 이름은 detail.png
- 버튼과 안내 문구는 저장된 이미지에 찍히지 않게 하고, 사진을 안 넣은 자리는 지금처럼 빈 네모로 둬
- 이미지 변환은 html-to-image 라이브러리로 해줘
- 다른 디자인은 바꾸지 말고, 전체 코드를 HTML 파일 하나로 다시 줘
  • 이미지로 바꾸는 도구를 인터넷에서 불러오므로 인터넷이 연결된 상태에서 누릅니다.
  • 대화 화면 안의 미리보기에서는 저장이 안 될 수 있습니다. 꼭 저장한 index.html을 Chrome에서 여세요.
  • 네이버 스마트스토어 상세설명 권장 너비는 가로 860px, 이미지 한 장은 20MB까지입니다. 상세가 4000px을 넘으면 위 3000px만 먼저 보이고 나머지는 접히므로 핵심 문구와 특징을 위쪽에 둡니다(2026-09-30 확인).
  • 쿠팡은 WING 등록 화면에 뜨는 크기 안내를, 와디즈는 가로 1024px 이하를 따릅니다.
  • 상품정보제공고시는 상세 이미지와 별도로 등록 화면에서 입력하는 필수 항목입니다.

사진이 위아래(또는 양옆)로 잘려 보이면 정상입니다. 사진 자리를 빈틈없이 채우려고 넘치는 부분을 자른 것입니다. 사진 전체가 보이게 하려면 같은 대화에 아래 문장을 보내고, 새로 받은 코드로 폴더의 index.html을 바꿔 넣습니다. 대신 사진마다 자리 높이가 달라집니다.

사진을 자르지 말고 전체가 보이게 해줘. 사진 자리의 가로 너비는 그대로 두고, 높이는 넣은 사진의 비율에 맞춰 늘거나 줄게 해줘. 다른 디자인은 바꾸지 말고 전체 코드를 HTML 파일 하나로 다시 줘.

이 결과물을 개발자에게 넘길 전달 메모를 써줘. 아래 항목을 표나 목록으로.
- 아직 채우지 않은 [ ] 칸과 사진 자리: 위치와 들어갈 내용
- 쓴 글꼴 이름과 불러오는 주소, 쓴 색 값 (design-system.md와 다른 값이 있으면 표시)
- 기준 화면 너비와 확인할 기기 (휴대폰, 노트북)
- 아직 동작하지 않는 것 (버튼, 문의 양식, 링크)
- 이 결과물을 만들 때 쓴 부탁 문장

# 정시로 디자인 시스템

> 가상 브랜드: 물류 관제 B2B 솔루션
> 이 파일로 만들기 좋은 결과물: 발표·제안용 슬라이드

## 1. 글자
본문 폰트: Nanum Gothic
제목 폰트: Sunflower (숫자도 이 폰트)
크기: 제목 56px / 소제목 32px / 본문 28px / 핵심 숫자 200px, 줄간격 1.5
굵기: 본문 400, 제목 700, 핵심 숫자 700

## 2. 색
배경:      #EDEEEA
카드·면:   #FFFFFF   (표와 막대 차트 바탕에만)
글자:      #111311
보조 글자: #555A54
강조:      #F2B705   (지게차 노랑. 핵심 숫자 밑 띠, "지연" 표시의 바탕, 버튼 호버 띠에만. 글자색으로는 쓰지 않음)
테두리:    #C9CCC5

## 3. 여백과 모양
기본 간격: 8px (이 값의 배수만 사용)
모서리 둥글기: 버튼 0px, 카드 0px
그림자: 없음

## 4. 레이아웃
- 16:9 슬라이드. 왼쪽 3분의 1에 제목과 설명 두 줄, 오른쪽 3분의 2에 숫자 하나 또는 표 하나
- 한 장에 핵심 숫자는 하나만. 숫자 밑에 강조색 띠를 깔고 단위를 작게 붙인다
- 차트는 가로 막대만. 막대는 글자색, 비교 대상 하나만 강조색
- 제목은 왼쪽 위, 결론을 문장으로 쓴다 ("배차 지연 38% 감소")

## 5. 쓰지 말 것
- 어두운 관제실 화면 (검정 배경 + 형광색 선)
- 지도, 지구본, 트럭 일러스트와 아이콘
- 아이콘 + 숫자 카드 4개를 나란히 놓은 대시보드 모양
- 원형 차트, 3D 차트
- 파랑·남색 계열
- 그라디언트, 그림자
- "혁신", "스마트", "올인원" 같은 막연한 단어
- 순서가 아닌 내용에 붙는 번호 (1 2 3, 01 02 03)
- 가운뎃점(·)으로 이은 머리글이나 꼬리글

## 6. 성격
이런 느낌 (형용사 3개): 정확한, 절제된, 숫자가 주인공인
이런 건 아님 (참고하면 안 되는 예 2개): SF 영화 속 관제실 화면, 스타트업 투자 설명회 장표

## 8. 컴포넌트 상태
버튼
- 기본: 글자색 바탕, 흰 글자, 모서리 0
- 호버: 바탕은 그대로, 아래에 강조색 4px 띠
- 포커스(키보드): 글자색 3px 외곽선, 3px 띄움 (노랑은 연회색 위에서 잘 안 보여서 쓰지 않음)
- 비활성: 보조 글자색 바탕, 흰 글자, 커서 금지 표시. 투명도로 흐리게 하지 않는다
입력창
- 기본: 흰 바탕, 1px 테두리색
- 포커스: 2px 글자색 테두리
- 오류: 2px 글자색 테두리 + 아래에 "오류:"로 시작하는 문장. 색만으로 알리지 않는다
- 비활성: 배경색 바탕, 보조 글자색 글자

1. 어떤 서버에 연결하나

  • 원격 서버 (https://mcp.figma.com/mcp): 가이드에 "모든 시트 및 요금제에서 사용할 수 있습니다"라고 적혀 있습니다. 이 세션은 원격 서버를 기준으로 합니다.
  • 데스크톱 서버: 가이드에 "데브 또는 풀 시트에서 모든 유료 요금제"라고 적혀 있습니다.
  • 요청 한도: 요금제·좌석별 사용량 한도는 Figma 개발자 문서에 따로 있습니다. 이 자료에는 숫자를 적지 않습니다(미확인).

2. Claude Code에 연결하기

터미널에서 둘 중 하나를 실행합니다.

claude plugin install figma@claude-plugins-official

또는

claude mcp add --transport http figma https://mcp.figma.com/mcp

그다음 순서입니다.

  1. Claude Code를 새로 시작합니다.
  2. /mcp를 입력하고 figma를 고른 뒤 Authenticate를 누릅니다.
  3. 브라우저 창에서 Allow Access를 누릅니다.
  4. "Authentication successful. Connected to figma"가 보이면 연결된 것입니다. /mcp로 한 번 더 확인합니다.

3. 시연 두 방향

① Figma 변수 → design-system.md (실습①)

  1. 변수(Variables)가 정의된 Figma 파일 링크를 복사합니다.
  2. advanced/prompts.md의 "토큰 추출: Figma 파일에서" 프롬프트에 링크를 넣어 보냅니다.
  3. docs/design-system.md의 색·간격 칸이 Figma 값으로 채워졌는지 확인합니다. Figma에 없는 값은 "(없음)"이어야 합니다.

② 로컬 화면 → Figma 레이어 (실습③ 마지막)

  1. index.html을 로컬에서 띄웁니다.
  2. "Figma로 보내기" 프롬프트에 대상 Figma 파일 링크를 넣어 보냅니다.
  3. 가이드에 따르면 화면을 Figma로 캡처하는 기능은 원격 서버에서만, 그리고 일부 클라이언트(Claude Code 포함)에서만 됩니다.

4. 연결에 실패하면

  • 인증 창이 뜨지 않거나 실패함: 현장 와이파이 문제일 가능성이 큽니다. 휴대폰 핫스팟으로 한 번만 다시 시도하고, 그래도 안 되면 중단합니다.
  • 권한·좌석 오류: 요금제나 좌석 문제입니다. 현장에서는 해결할 수 없으니 중단합니다.
  • 대안: 진행자가 미리 찍어 둔 스크린샷(demo/figma-roundtrip/)으로 흐름만 보여줍니다. 스크린샷이 아직 없으면 이 문서의 3장을 말로 설명합니다.
  • 변수 없이 하는 방법: Figma 없이도 실습①의 "토큰 추출: 코드에서" 프롬프트로 같은 결과(토큰이 채워진 design-system.md)를 만들 수 있습니다.
