# 정시로 디자인 시스템

> 가상 브랜드: 물류 관제 B2B 솔루션
> 이 파일로 만들기 좋은 결과물: 발표·제안용 슬라이드

## 1. 글자
본문 폰트: Nanum Gothic
제목 폰트: Sunflower (숫자도 이 폰트)
크기: 제목 56px / 소제목 32px / 본문 28px / 핵심 숫자 200px, 줄간격 1.5
굵기: 본문 400, 제목 700, 핵심 숫자 700

## 2. 색
배경:      #EDEEEA
카드·면:   #FFFFFF   (표와 막대 차트 바탕에만)
글자:      #111311
보조 글자: #555A54
강조:      #F2B705   (지게차 노랑. 핵심 숫자 밑 띠, "지연" 표시의 바탕, 버튼 호버 띠에만. 글자색으로는 쓰지 않음)
테두리:    #C9CCC5

## 3. 여백과 모양
기본 간격: 8px (이 값의 배수만 사용)
모서리 둥글기: 버튼 0px, 카드 0px
그림자: 없음

## 4. 레이아웃
- 16:9 슬라이드. 왼쪽 3분의 1에 제목과 설명 두 줄, 오른쪽 3분의 2에 숫자 하나 또는 표 하나
- 한 장에 핵심 숫자는 하나만. 숫자 밑에 강조색 띠를 깔고 단위를 작게 붙인다
- 차트는 가로 막대만. 막대는 글자색, 비교 대상 하나만 강조색
- 제목은 왼쪽 위, 결론을 문장으로 쓴다 ("배차 지연 38% 감소")

## 5. 쓰지 말 것
- 어두운 관제실 화면 (검정 배경 + 형광색 선)
- 지도, 지구본, 트럭 일러스트와 아이콘
- 아이콘 + 숫자 카드 4개를 나란히 놓은 대시보드 모양
- 원형 차트, 3D 차트
- 파랑·남색 계열
- 그라디언트, 그림자
- "혁신", "스마트", "올인원" 같은 막연한 단어
- 순서가 아닌 내용에 붙는 번호 (1 2 3, 01 02 03)
- 가운뎃점(·)으로 이은 머리글이나 꼬리글

## 6. 성격
이런 느낌 (형용사 3개): 정확한, 절제된, 숫자가 주인공인
이런 건 아님 (참고하면 안 되는 예 2개): SF 영화 속 관제실 화면, 스타트업 투자 설명회 장표

## 7. 토큰 (코드용)
:root {
  --color-bg: #EDEEEA;
  --color-surface: #FFFFFF;
  --color-text: #111311;
  --color-text-muted: #555A54;
  --color-accent: #F2B705;
  --color-border: #C9CCC5;
  --space-1: 8px;          /* 기본 간격. 나머지는 이 값의 배수 */
  --radius-button: 0px;
  --radius-card: 0px;
  --font-body: "Nanum Gothic", sans-serif;
  --font-display: "Sunflower", sans-serif;
}
토큰 이름 규칙: --종류-역할 (예: --color-accent)
값을 드러내는 이름(--yellow-500)은 쓰지 않는다

## 8. 컴포넌트 상태
버튼
- 기본: 글자색 바탕, 흰 글자, 모서리 0
- 호버: 바탕은 그대로, 아래에 강조색 4px 띠
- 포커스(키보드): 글자색 3px 외곽선, 3px 띄움 (노랑은 연회색 위에서 잘 안 보여서 쓰지 않음)
- 비활성: 보조 글자색 바탕, 흰 글자, 커서 금지 표시. 투명도로 흐리게 하지 않는다
입력창
- 기본: 흰 바탕, 1px 테두리색
- 포커스: 2px 글자색 테두리
- 오류: 2px 글자색 테두리 + 아래에 "오류:"로 시작하는 문장. 색만으로 알리지 않는다
- 비활성: 배경색 바탕, 보조 글자색 글자
