# AI 클로드코드 모임 세션 준비 자료

세션마다 폴더 하나에 자료를 모은다. 각 폴더의 `README.md`에 여는 법과 다시 만드는 법이 있다.

| 폴더 | 세션 | 상태 |
| --- | --- | --- |
| `style-file-session/` | 매번 달라지는 AI 결과물, 클로드 설정으로 통일해보기 | 끝남 |
| `cowork-session/` | 퇴근 후에도 일하는 AI 직원 만들기: Cowork로 내 일 통째로 맡기기 | 준비 중 |

각 폴더의 `HANDOFF.md`는 내부 기획 문서라 저장소에 올리지 않고 로컬에만 둔다.
