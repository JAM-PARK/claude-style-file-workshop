왜 다 똑같이 생겼나

AI는 가장 그럴듯한 다음 단어를 고릅니다.
디자인에서 "가장 그럴듯한 것"은 수많은 템플릿의 평균입니다.
모든 랜딩페이지의 평균은 가운데 큰 제목, 파란 버튼, 카드 3개입니다.

평균은 스타일이 아니라, 스타일이 없는 상태입니다.

4 / 16

제약이 없으면 학습 데이터의 평균으로 갑니다. 3번 스와치 8개가 바로 그 평균입니다.

왜 매번 까먹나

대화는 매번 새로 시작합니다. 이전 대화에서 넘어오는 건 없습니다.
대화창은 작업대이지 서랍이 아닙니다.
남겨야 할 것은 서랍(파일, 프로젝트, 설정)에 넣어야 합니다.

대화가 길어질수록 앞에서 한 말을 놓칩니다.
길게 설명하는 것보다 짧고 정확한 파일 하나가 낫습니다.

잘 채우는 규칙 3개

  1. 모호한 말은 안 됩니다. 깔끔한 고딕이라고 쓰면 AI는 늘 쓰던 폰트를 고릅니다. 따뜻한 빨강은 매번 다르게 해석됩니다. 폰트는 이름으로, 색은 # 값으로.

  2. "쓰지 말 것"이 더 중요합니다. 대부분 원하는 것만 적습니다. 하지 말 것을 적어두면 AI가 기본값으로 채울 자리가 사라집니다.

  3. 배치부터 정합니다. 평범해지는 건 색이 아니라 배치에서 시작됩니다. 흔한 배치 위에 내 색 버튼만 올리면, 색만 다른 똑같은 AI 페이지가 됩니다.

# 뜨개 도안 디자인 시스템
세션 ② 장표, 배포 페이지, 러닝시트가 이 도안 한 장을 따른다.
도안과 범례만 있으면 누가 떠도 같은 옷이 나온다.
## 1. 글자
본문 폰트: Gothic A1 (보통 400, 중간 500)
제목 폰트: Gothic A1 (굵게 700)
원문 폰트: Nanum Gothic Coding (원문에만. 서브셋 이름 S2 Mono)
대체 폰트: "Apple SD Gothic Neo", "Malgun Gothic", sans-serif
굵게: 문장 앞머리나 한 줄 전체에만 700
숫자: Gothic A1 숫자는 폭이 같아 타이머·단 번호에 그대로 쓴다
크기 (장표 1920×1080)
제목 72px / 소제목 44px / 본문 32px / 꼬리표 24px
줄간격 본문 1.6, 제목 1.3
크기 (배포 페이지, 휴대폰)
제목 28px / 소제목 20px / 본문 17px, 줄간격 1.7 (제목 1.3)
크기 (러닝시트, A4)
제목 16pt / 본문 10pt / QR 주소 8pt, 줄간격 1.45 (제목 1.3)
A4 한 장에 넣으려고 기본 간격 4px, 표 칸 위아래 여백 1px
## 2. 색 (범례. 여기 없는 색은 없다)
도안지 (배경): #FFFFFF
모눈 (칸 선): #DCDCD6
먹실 (글자): #1E1E1C
흐린 먹 (보조): #5E5E58
이끼실 (강조): #3F6B3A 버튼 테두리, 링크, 포커스
줄자 (지금 여기): #E3B21A 현재 줄, 가장 중요한 칸, 끝난 타이머
코 없음: #CFCFC9 "쓰지 말 것" 표시 칸
투명도나 섞어서 만든 중간색은 쓰지 않는다.
## 3. 여백과 모양
기본 간격: 8px (이 값의 배수만 사용)
모눈 한 칸: 40px. 블록의 위치와 너비는 칸 단위로 잡는다
장표 여백: 왼쪽 4칸, 위 3칸, 오른쪽 4칸, 아래 2칸
모서리 둥글기: 모두 0
그림자: 없음
선: 모눈과 표는 1px 모눈색, 스와치 테두리와 버튼은 2px
## 4. 레이아웃
모든 화면은 왼쪽 정렬 한 단이다. 제목은 왼쪽 위에 둔다.
2열은 트랙 비교(11, 12, 13번)와 A/B 비교(7번)에만 쓴다.
모눈은 칸 맞춤용이다. 눈에 보이게 까는 곳은 표지와 15번뿐이다.

## 5. 쓰지 말 것
- 가운데 정렬 제목 (표지 포함)
- 그라디언트, 반투명 유리 효과, 빛 번짐, 그림자
- 카드, 카드 격자, 둥근 모서리
- 파랑, 남색, 보라, 범례 밖의 모든 색
- 이모지, 아이콘, 일러스트, 장식 이미지
- 제목 위 영문 대문자 라벨, 제목 안 한 단어만 강조
- 등장 효과 (슬라이드 전환만 허용)
- 링크·버튼 끝 화살표, 순서가 아닌 내용에 붙는 번호
- 작은 라벨용 고정폭 폰트
- 내용을 묶으려고 두르는 테두리 상자 (8장 부품에 적힌 칸만 허용)
## 6. 성격
이런 느낌: 정확함, 차분함, 따라 하면 되는
이런 건 아님: 서비스 소개 랜딩페이지, 귀여운 공방 소품
## 7. 이 장표만의 원칙
1. 남이 뜬 것은 스와치로만 보여준다. 스와치 안은 인용이며 이 도안을 따르지 않는다 (3번, 7번).
2. 노랑은 "여기를 보라"에만 쓴다. 장표는 한 화면에 한 군데.
배포 페이지는 "쓰지 말 것" 제목 줄과 선택된 탭에 쓴다.
3. 힘은 15번에 한 번만 준다. 15번에서 이 도안 원문이 모눈 위에 펼쳐진다.
## 8. 부품
스와치: 2px 먹실 테두리, 아래에 꼬리표(흐린 먹, 24px)로 무엇을 어떻게 떴는지
스와치 판: 3번은 스와치 8개를 4×2 칸에, 7번은 2개를 나란히 건다
범례: 한 칸(40px) 색 칩 + 이름 + 값, 세로로 쌓는다.
예시끼리 비교할 때는 칩만 가로 한 줄 (예시의 색은 인용)
코 없음 칸: 글자 높이의 회색 네모. "쓰지 말 것" 항목 앞에 붙인다
