심화 트랙 동선

  • Claude Code 설치·로그인이 끝난 사람만. 설치부터 해야 하면 기본 트랙으로
  • 배포 페이지 심화 탭으로 스스로 진행. 블록이 끝날 때마다 심화 쪽을 1분 확인
  • 2명 이상이면 한 테이블에서 같은 파일로 뽑은 화면을 비교. Figma MCP는 실습③을 끝낸 사람만

막혔을 때

노트북 없음옆자리와 2인 1조. 휴대폰으로 배포 페이지를 열어 예시를 고르고 입력은 짝의 노트북으로
무료 계정이라 기능이 없음프로젝트는 무료도 5개까지. 막히면 첫 메시지에 파일 첨부. 한도에 걸리면 요금제별 차이를 안내
결과물이 마음에 안 듦다시 생성하지 말고 보조 2 프롬프트로 "어느 칸이 비어서 그랬는지" 같이 찾기. 이게 세션의 핵심 학습

현장 체크리스트

  • 장표·배포 페이지 오프라인 동작 확인
  • 배포 페이지 QR을 장표 8번과 인쇄물 양쪽에
  • A/B 시연 스크린샷 두 쌍 확인
  • 타이머 3개 동작 확인 (10, 11, 13번)
  • 노트북 미지참자용 인쇄물: 예시 3종 + 결과물 스크린샷
  • 진행자 계정에 예시 B로 설정된 프로젝트 만들어두기

마무리 기록란
