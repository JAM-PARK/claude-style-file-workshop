# 세션 ② 기본 트랙 진행 가이드

## 자료는 세 가지입니다

| 자료 | 누가 보나요 | 여는 법 |
| --- | --- | --- |
| **장표** (발표 화면) | 진행자가 화면에 띄웁니다 | 내 노트북의 `slides/index.html` 파일을 Chrome으로 엽니다. 인터넷이 없어도 열립니다 |
| **배포 페이지** | 참가자가 QR로 엽니다 | https://session02-handout.vercel.app |
| **러닝시트** | 진행자가 인쇄해서 손에 듭니다 | `runsheet/index.html`을 열어 인쇄합니다 |

장표는 인터넷에 올리지 않았습니다. 배포 페이지 주소로는 열리지 않습니다.

장표 파일 위치: `claude-style-file-workshop` 폴더 → `slides` 폴더 → `index.html`

## 장표 조작 키

장표를 띄운 채 키보드에서 누르는 키입니다.

| 하고 싶은 것 | 누를 키 |
| --- | --- |
| 다음 장 | 오른쪽 화살표 키 `→` 또는 스페이스바 |
| 이전 장 | 왼쪽 화살표 키 `←` |
| 발표자 메모 열기/닫기 | 알파벳 `N` 키. 화면 아래에 말할 내용과 지난 시간이 나옵니다. 한글 입력 상태여도 됩니다 |
| 7장에서 웹페이지 비교 보기 | 숫자 `1` 키, 또는 화면의 **1 웹페이지** 버튼 (슬라이드 비교는 `2`) |
| 15장에서 노란 줄 한 칸 내리기/올리기 | 아래 화살표 키 `↓` / 위 화살표 키 `↑` |
| 타이머 시작 (10·11·13장) | 화면의 **시작** 버튼을 마우스로 누릅니다 |
| 전체 화면 | Mac은 `Control + Command + F`, Windows는 `F11` |

## 기본 트랙은 claude.ai 웹만으로 되나요?

네. 실습 세 개는 모두 claude.ai 웹에서 합니다. 설치할 것은 없습니다.

- 참가자는 **노트북**으로 합니다. 휴대폰은 배포 페이지를 보는 데만 씁니다.
- 결과물 창이 안 뜨면 claude.ai의 **설정 → 기능 → 클라우드 코드 실행 및 파일 생성**을 켭니다.
- 결과물을 밖으로 가져가는 마지막 단계만 Chrome과 Netlify를 씁니다. 이것도 설치 없이 됩니다.

## 준비

**세션 전**
- [ ] 진행자 claude.ai에 **시연용 프로젝트**를 만들어 둡니다(예시 A 파일 + 지침 한 줄). 참가자가 막히면 이 화면으로 대신 보여 줍니다.
- [ ] 러닝시트를 인쇄합니다.

**시작 10분 전**
- [ ] 장표를 열고 전체 화면으로 바꿉니다.
- [ ] 와이파이 정보를 칠판에 적습니다.
- [ ] 참가자 노트북에서 claude.ai 로그인이 되는지 확인합니다.

## 진행 대본 (60분)

### ① 문제 인식 · 0~5분 · 1~6장

- **2장:** "세션 ①은 한 번 잘 만드는 법, 오늘은 한 번 설정해서 계속 같게 만드는 법입니다."
- **3장:** 하나씩 설명하지 말고 "다 본 적 있죠?" 한 마디면 됩니다.
- **4장:** "평균은 스타일이 아니라, 스타일이 없는 상태입니다."
- **5장:** "대화창은 작업대이지 서랍이 아닙니다."
- **6장:** 한 문장을 천천히 읽습니다.

> 밀리면: 3장만 보여 주고 4~5장은 말로 한 줄씩.

### ② A/B 시연 · 5~10분 · 7장

- 숫자 `1` 키(또는 화면의 **1 웹페이지** 버튼)로 웹페이지 비교를 띄웁니다.
- "두 쪽에 보낸 부탁은 글자 하나까지 같습니다. 오른쪽만 스타일 파일을 설정했습니다."

### ③ 실습① 스타일 파일 만들기 · 10~25분 · 8~10장

**8장에서 할 일:** QR을 찍게 하고, 노트북에서도 같은 주소를 열게 합니다.

**참가자에게 셋 중 하나를 고르게 합니다.**

| 이런 분은 | 이렇게 |
| --- | --- |
| 참고할 사이트나 사진이 있다 | 캡처를 claude.ai에 올리고 **보조 1** 프롬프트 |
| 참고 자료가 없다 | **보조 3** 프롬프트. Claude가 보기를 주며 물어봅니다 |
| 시간이 없다 | 예시 A **파일로 받기** → 이름·색·글꼴만 바꾸기 |

**돌아다니며 세 가지만 봅니다.**
1. 글꼴이 이름으로 적혀 있나요? (예: Gowun Dodum)
2. 색이 `#`으로 시작하는 값인가요?
3. "쓰지 말 것"이 채워져 있나요?

**마무리:** AI가 만든 초안이면 같은 대화에 "이 내용을 design-system.md 파일로 만들어줘"라고 보내 파일로 받게 합니다.

> 밀리면: 예시 A를 그대로 쓰고 색과 글꼴만 바꾸게 합니다.

### ④ 실습② 클로드에 설정하기 · 25~35분 · 11장

진행자 화면을 띄우고 **한 단계씩 같이** 누릅니다.

1. 왼쪽 메뉴 **프로젝트** → 새 프로젝트
2. **프로젝트 지식**에 `design-system.md` 올리기
3. **프로젝트 지침**에 배포 페이지의 한 줄 붙여넣고 저장

> 파일이 안 올라가면: 배포 페이지 "파일이 안 올라가면"을 따라 지침 칸에 파일 내용을 통째로 붙여 넣습니다.

### ⑤ 실습③ 결과물 만들고 다시 확인 · 35~52분 · 12~14장

**12장:** 꼭 **프로젝트 안에서** 새 대화를 엽니다. 가장 흔한 실수입니다.
- 소개 웹페이지는 **시작 2**, 상세페이지는 **시작 3**을 복사합니다.
- `[ ]` 칸에 내 내용을 채워 보냅니다. 파일은 붙이지 않습니다.

**결과가 나오면 같이 봅니다.** 색과 글꼴이 파일에 적은 값이면 성공입니다.

**13장:** 같은 부탁을 새 대화에서 한 번 더 보냅니다. 같은 스타일이면 "설정이 된 겁니다."

**14장:** 다르게 나오면 다시 생성하지 말고 **보조 2**를 보냅니다. 어느 칸이 비었는지 찾아 파일을 고칩니다.

> 밀리면: 13장 재확인은 진행자 시연 프로젝트로 대신 보여 줍니다.

### ⑥ 마무리 · 52~60분 · 15~16장

- **15장:** `↓` 키로 노란 줄을 내리며 "이 장표도 이 파일 한 장으로 만들었습니다."
- **가져가기 안내:** 배포 페이지 맨 끝 "결과물 가져가기"를 가리킵니다. 집에서 해도 됩니다.
- **16장:** "오늘 만든 걸로 회사에서 뭘 해보고 싶으세요?" 대답을 러닝시트에 적습니다.

## 막혔을 때

| 이럴 때 | 이렇게 |
| --- | --- |
| 결과물 창이 안 뜬다 | 설정 → 기능 → 클라우드 코드 실행 및 파일 생성 켜기 |
| 스타일이 파일과 다르다 | 프로젝트 안 대화인지 확인 → 보조 2 |
| 파일이 안 올라간다 | 지침 칸에 내용 붙여넣기 |
| 사용량 한도에 걸렸다 | 진행자 시연 프로젝트로 이어서 보여 주기 |
| 코드가 `import`로 시작한다 | "HTML 파일 하나로 다시 줘" |
| 노트북이 없다 | 옆자리와 둘이 한 대로 |
| 결과가 마음에 안 든다 | 다시 생성 말고 보조 2 |
| 상세페이지에 넣은 사진이 위아래로 잘린다 | 정상입니다. 전체를 보이게 하려면 배포 페이지 "결과물 가져가기 → 2" 아래쪽 문장을 보냅니다 |
