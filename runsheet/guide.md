# 세션 ② 기본 트랙 진행 가이드

진행자용 문서다. 러닝시트(`runsheet/index.html`, A4 한 장)는 현장에서 들고 보는 요약이고, 이 문서는 그 해설이다. 참가자 자료는 모두 배포 페이지(https://session02-handout.vercel.app) 한 곳에 있다.

## 0. 한눈에

**오늘의 한 문장** (6번 장표)
> AI는 까먹는 게 아니라 애초에 못 들은 겁니다. 매번 말로 설명하는 대신 파일로 주면 둘 다 해결됩니다.

**참가자가 들고 가는 것 3가지** (2번 장표)
1. 내 스타일 파일 `design-system.md` 1개
2. 그 파일이 설정된 claude.ai 프로젝트 1개
3. 설정만으로 만든 결과물 1개 (소개 웹페이지 또는 상세페이지)

**진행 원칙 3가지**
- **다시 생성 버튼을 누르지 않게 한다.** 결과가 어긋나면 파일의 빈칸을 찾아 고친다. 이게 세션의 핵심 학습이다(14번).
- **밀리면 실습③을 지킨다.** "설정한 뒤 새 대화에서 파일 없이 부탁했는데 같은 스타일로 나온다"가 세션 제목의 증명이다. 앞 블록을 줄여서라도, 참가자가 직접 못 하면 진행자 화면으로라도 이 장면은 남긴다.
- **막히면 진행자 화면으로 대신 보여 준다.** 진행자 계정의 시연용 프로젝트(예시 A)가 모든 실습의 대비책이다.

## 1. 기본 트랙은 claude.ai 웹만으로 되나요

실습①~③은 **claude.ai 웹(또는 Claude 데스크톱 앱)만으로 된다.** 설치할 것은 없다. 결과물을 밖으로 가져가는 단계만 claude.ai 밖(배포 페이지, Chrome, Netlify)에서 하고, 그것도 설치 없이 브라우저로 끝난다.

| 단계 | 하는 곳 | 비고 |
| --- | --- | --- |
| 실습① 스타일 파일 만들기 | 배포 페이지(템플릿·예시) + claude.ai 대화(보조 1·3) | 참고 캡처는 대화에 이미지로 올린다 |
| 실습② 설정하기 | claude.ai 프로젝트 | 프로젝트 지식에 파일, 프로젝트 지침에 한 줄 |
| 실습③ 결과물 만들기·다시 확인 | claude.ai 프로젝트 안의 새 대화 | 결과물은 대화 옆 결과물 창(아티팩트)에 뜬다 |
| 가져가기 (숙제 가능) | 배포 페이지 저장 칸 → Chrome → (소개 페이지) Netlify Drop | 인터넷 필요. 소개 페이지 링크는 Netlify 무료 가입 |

**조건과 주의** (support.claude.com, 2026-09-30~10-01 확인)
- **노트북 웹 브라우저로 한다.** 휴대폰 앱은 결과물을 보는 것까지만 권한다. 도움말도 편집과 공유 설정은 웹이나 데스크톱에서 하라고 안내한다. 배포 페이지의 "파일로 받기"도 휴대폰에서 누르면 파일이 휴대폰에 저장된다.
- **결과물 창이 안 뜨면** 설정 > 기능에서 "클라우드 코드 실행 및 파일 생성"을 켠다. Free·Pro·Max는 기본으로 켜져 있다.
- **무료 계정**
  - 프로젝트는 5개까지 만들 수 있다.
  - 메모리는 기본으로 켜져 있다.
  - 사용량은 5시간마다 초기화되고 한도가 낮다. 긴 상세페이지를 여러 번 만들면 중간에 막힐 수 있다.
  - 결과물 링크 공유가 안 된다. 그래서 가져가기는 Netlify Drop이나 이미지로 한다.
- **확인하지 못한 것**
  - 화면의 실제 메뉴 이름. 이 문서는 도움말 번역 기준이다.
  - 무료 계정의 결과물 창에 다운로드 버튼이 있는지
  - 프로젝트 지식에 `.md` 파일이 올라가는지
  - 결과물 창 미리보기에서 Google Fonts 글꼴이 보이는지
  
  각각의 대비책은 5장 "막혔을 때"에 있다.

## 2. 준비

**전날~당일 아침**
- [ ] 신청자 답장 확인: 만들 것(소개 웹페이지/상세페이지), 참고 자료, 무료/유료 계정, 사진(JPG)
- [ ] 진행자 claude.ai에 시연용 프로젝트를 만든다. 예시 A(배포 페이지 "파일로 받기")를 프로젝트 지식에 올리고, 지침 한 줄을 넣는다. 그 안에서 시작 2와 시작 3을 한 번씩 돌려 결과를 남겨 둔다.
- [ ] 상세페이지 "이미지로 저장" 흐름을 내 노트북에서 한 번 끝까지 해 본다(배포 페이지 "결과물 가져가기" 2번)
- [ ] 러닝시트 새 버전 인쇄, 장표(`slides/index.html`)가 인터넷 없이 열리는지 확인

**현장 10분 전**
- 장표를 전체화면으로 연다. `N`을 누르면 발표자 노트와 경과 시간이 보인다.
- 와이파이 이름과 비밀번호, 배포 페이지 주소를 화이트보드에 적는다.
- 참가자 노트북에서 claude.ai 로그인이 되는지 먼저 확인한다. 로그인이 막히면 실습 전체가 막힌다.

## 3. 블록별 진행 (60분)

### 0~5분 · 문제 인식 (1~6번)
- **2번:** 세션 ①과의 차이를 한 줄로 말한다. "①은 한 번 잘 만들기, ②는 설정해서 계속 같게."
- **3번:** 하나씩 설명하지 않는다. "다 본 적 있죠?" 한 번이면 된다.
- **4번:** "평균은 스타일이 아니라, 스타일이 없는 상태입니다."
- **5번:** 오늘의 비유는 "대화창은 작업대이지 서랍이 아닙니다." 서랍은 11번에서 실제로 만든다.
- **6번:** 한 문장을 천천히 읽고 넘어간다.
- 1번 노트의 손 들기 질문은 신청자가 모두 기본 트랙이라 생략한다. 현장에 추가 참가자가 있을 때만 "Claude나 ChatGPT로 문서를 만들어 보셨나요?" 하나를 묻는다.
- **밀리면** 3번만 보여 주고 4~5번은 말로 한 줄씩.

### 5~10분 · A/B 시연 (7번)
- 참가자 결과물이 웹 쪽이니 `1`(웹페이지)을 보여 준다.
- 말할 것:
  - "두 쪽 프롬프트는 글자 하나까지 같습니다. 오른쪽만 프로젝트에 스타일 파일을 넣었습니다."
  - "왼쪽은 하나도 고치지 않은 AI 기본값이고, 3번에서 본 그 모습입니다."

### 10~25분 · 실습① 스타일 파일 만들기 (8~10번, 타이머 15분)
- 8번에서 QR을 찍게 한다. 그리고 **노트북에서도 같은 주소를 열게 한다.** 파일 받기와 복사는 노트북에서 해야 한다.
- 출발점을 사람마다 하나 고르게 한다.

| 상황 | 경로 |
| --- | --- |
| 참고 자료(사이트, 전단, 사진)가 있다 | 캡처를 claude.ai 대화에 올리고 **보조 1** + 빈칸 템플릿 붙여넣기 |
| 참고 자료가 없다, 디자인이 막막하다 | **보조 3**: Claude가 보기 3개씩 주며 질문한다. 번호만 골라도 된다 |
| 시간이 없다 | 예시 A **파일로 받기** → 이름·색·글꼴만 바꾸기 |

- **진행자가 돌며 볼 것** (9번 규칙과 보조 프롬프트 기준)
  - 글꼴이 "깔끔한 고딕"이 아니라 이름(예: Gowun Dodum)으로 적혀 있나
  - 색 6칸이 #값인가
  - "쓰지 말 것"이 4줄 이상인가. 비어 있으면 "AI가 기본값으로 채운다"고 짚는다
  - 보조 1 초안의 "(추측)" 표시 값을 본인이 확인했나
  - 레이아웃 칸에 배치가 적혀 있나. 가운데 큰 제목과 카드 3개 같은 흔한 배치면 색만 바꾼 AI 페이지가 된다
- **보조 1·3으로 만든 초안은 대화 안의 글이다.** 끝나면 같은 대화에 "이 내용을 design-system.md 파일로 만들어줘"라고 보내 파일로 받게 한다(배포 페이지 설정 안내에 있음). 파일이 안 나오면 초안을 복사해 두었다가 실습②에서 지침에 붙인다.
- 상세페이지를 만들 분의 예시 A에서 "반찬 전용 줄"(요일 식단표, 사진 구도, "이번 주 받아보기")은 내 내용으로 바꾸게 한다.
- **밀리면** 예시 A를 그대로 쓰고 색과 글꼴만 바꾼다.

### 25~35분 · 실습② 클로드에 설정하기 (11번, 타이머 10분)
진행자 화면을 띄우고 **한 단계씩 같이** 누른다. 혼자 하게 두면 여기서 가장 많이 멈춘다.

1. 왼쪽 메뉴 **프로젝트** → 새 프로젝트 (이름은 "내 스타일" 정도)
2. **프로젝트 지식**에 `design-system.md`를 올린다.
3. **프로젝트 지침**에 한 줄을 붙여 넣고 저장한다. 배포 페이지에서 복사한다.
   ```
   모든 결과물은 프로젝트 지식의 design-system.md를 따른다. 문서에 없는 스타일은 쓰지 않는다.
   ```
4. (선택) 설정에서 메모리가 켜져 있는지 본다.

- **확인:** 프로젝트 화면에 파일 이름이 보이고 지침이 저장됐으면 끝.
- **파일이 안 올라가면** 지침 칸에 아래 줄을 쓰고 그 아래에 파일 내용을 전부 붙여 넣는다.
  ```
  모든 결과물은 아래 디자인 시스템을 따른다. 문서에 없는 스타일은 쓰지 않는다.
  ```
- **무료 계정의 프로젝트 5개가 꽉 찼으면** 새 대화 첫 메시지에 파일을 첨부하고 "이 파일을 따라줘"라고 쓴다.
- **밀리면** 메모리는 건너뛴다.

### 35~52분 · 실습③ 결과물 만들고 다시 확인 (12~14번, 타이머 17분)
- **12번:** 반드시 **프로젝트 안에서** 새 대화를 연다. 프로젝트 밖 대화에서는 설정이 읽히지 않는다. 가장 흔한 실수다.
  - 소개 웹페이지는 **시작 2**, 상세페이지는 **시작 3**을 복사해 `[ ]`에 본인 내용을 채운다.
  - 파일은 붙이지 않는다. 설정이 됐는지 확인하는 실험이다.
- **결과가 뜨면 같이 본다.** 배경색, 강조색, 글꼴이 파일에 적은 값인지 확인한다.
  - 상세페이지는 지어낸 후기나 수치가 없고 모르는 칸이 `[ ]`로 남아 있으면 정상이다. `[ ]`는 나중에 본인이 채울 칸이라고 알려 준다.
- **13번:** 같은 부탁을 새 대화에서 한 번 더 보낸다. 같은 스타일이면 "설정이 된 겁니다."
  - 무료 계정이면 한도를 아끼려고 짧은 부탁("핵심 문구와 특징 부분만 다시 만들어줘")으로 바꿔도 된다.
- **14번:** 다르게 나오면 **보조 2**를 보내 "어느 칸이 비어서 그랬는지" 찾는다.
  1. 파일을 고친다.
  2. 프로젝트 지식의 파일을 바꿔 넣는다.
  3. 다시 부탁한다.
  
  실제 사례는 14번 노트에 있다. 번호와 가운뎃점 머리글이 나왔는데, "쓰지 말 것"에 두 줄을 더했더니 사라졌다.
- **밀리면** 13번 재확인은 진행자 시연 프로젝트로 대신 보여 준다.

### 52~60분 · 이 장표의 비밀 + 다음 단계 (15~16번)
- **15번:** `↓` `↑`로 노란 줄자를 움직이며 짚는다. 순서는 2. 색 → 5. 쓰지 말 것 → 7. 원칙 1 → 8. 타이머와 스와치.
  - "이 장표에 이 파일에 없는 스타일은 하나도 없습니다. 방금 여러분이 만든 것과 같은 종류의 파일입니다."
- **결과물 가져가기 안내 (1분):** 배포 페이지 기본 트랙 탭 맨 아래의 "결과물 가져가기"를 가리킨다. 시간이 남으면 현장에서 같이 한다.
  - 소개 웹페이지: `index.html`로 저장 → 사진 넣기 → Netlify Drop(무료 가입 먼저)
  - 상세페이지: "이미지로 저장" 프롬프트 → 저장 → Chrome에서 사진 고르고 저장 → `detail.png`
- **16번:** "오늘 만든 걸로 회사에서 뭘 해보고 싶으세요?" 대답을 러닝시트 기록란에 적는다. "다음 주 주간 보고"처럼 구체적인 대상을 말하면 재참석 신호다.

## 4. 결과물별 동선

| | 소개 웹페이지 | 상세페이지 |
| --- | --- | --- |
| 출발 예시 | 예시 A (소개 웹페이지 줄: 본문 최대 720px, 버튼 하나) | 예시 A (상세페이지 줄: 가로 860px, 버튼 없음) |
| 실습③ 프롬프트 | 시작 2 | 시작 3 |
| `[ ]`에 넣을 것 | 소개 문구, 하는 일, 연락처 | 가격, 크기·용량, 구성, 배송, 특징 메모 |
| 결과에서 볼 것 | 색·글꼴이 파일 값인지, 가운데 큰 제목·카드 3개가 없는지 | 위 3000px 안에 핵심 문구와 특징이 있는지, 지어낸 후기·수치가 없는지 |
| 가져가기 | Netlify Drop 링크 | "이미지로 저장" → 860px PNG → 스마트스토어 등 업로드 |

## 5. 막혔을 때

| 증상 | 대응 |
| --- | --- |
| 결과물 창이 안 뜨고 코드만 나온다 | 설정 > 기능 > "클라우드 코드 실행 및 파일 생성" 켜기 |
| 스타일이 파일과 다르게 나온다 | ① 프로젝트 안의 대화인지 ② 지침이 저장됐는지 ③ 보조 2로 빈칸 찾기 |
| 미리보기의 글꼴이 파일과 다르다 | 미리보기 창의 한계일 수 있다. 저장해서 Chrome으로 열어 확인한다 (미확인) |
| 프로젝트 지식에 파일이 안 올라간다 | 지침에 첫 줄 + 파일 내용 붙여넣기 (3장 실습②) |
| 사용량 한도에 걸렸다 | 진행자 시연 프로젝트로 이어서 보여 준다. 5시간 뒤 초기화된다고 안내하고, 요금제 차이는 그때 짧게 |
| 결과물 창에 다운로드 버튼이 없다 | 코드를 복사해 배포 페이지 저장 칸에 붙여 `index.html`로 받는다 |
| 코드가 `import`로 시작한다 | "HTML 파일 하나로 다시 줘" |
| "이미지로 저장"이 안 된다 | 인터넷 연결 확인. 대화 미리보기가 아니라 저장한 `index.html`을 Chrome에서 열었는지 확인 |
| 사진이 안 보인다 | 아이폰 사진(.heic)이면 JPG로 바꾼다. 파일 이름이 코드 속 이름과 같은지 본다 |
| 노트북이 없다 | 옆자리와 2인 1조. 휴대폰으로 배포 페이지를 보고 입력은 짝의 노트북으로 |
| 결과물이 마음에 안 든다 | 다시 생성하지 않는다. 보조 2로 빈칸을 찾아 파일을 고친다 |

## 6. 말할 때

- **"디자인 시스템"보다 "스타일 파일"이라고 부른다.** 파일 이름만 `design-system.md`다.
- **처음 나오는 말은 한 줄로 풀어 준다.**
  - 아티팩트: 대화 옆에 뜨는 결과물 창
  - HTML: 브라우저로 여는 웹페이지 파일
  - 프로젝트 지식: 프로젝트 안 대화가 늘 읽는 서랍
- **AI 결과의 수치와 연락처는 지어낸 것일 수 있다고 짚는다.** 시작 2·3은 지어내지 말고 `[ ]`로 비우게 해 두었다.

## 7. 끝나고

- 러닝시트 기록란에 사람마다 한 줄을 남긴다: 이름 / 트랙 / 스타일 파일 / 설정 완료 / 집에서 해볼 것
- 성공 지표 3가지
  1. 스타일 파일을 만들었나
  2. 실제로 설정했나
  3. "집에서 이것도 해보고 싶다"는 구체적 대상을 말했나
