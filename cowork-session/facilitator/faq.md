# 예상 질문과 답변

진행자용. 답은 2~4문장, 입문자 눈높이로 한다. 제품 사실은 `PRODUCT.md`의 "확인한 사실" 범위에서만 말하고, 확인되지 않은 것은 `[확인 필요]`로 둔다. 리허설 때 확인한 뒤 해당 줄을 고친다.

출처:
- Cowork 시작하기: https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork
- 예약 작업: https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork

## 지난 세션에서 실제로 나온 질문

### 1. Cowork에서 한 일을 Chat이 왜 모르나요? (맥락 분리)
[확인 필요] 공식 문서는 클라우드에서 실행한 작업(내 컴퓨터가 아니라 인터넷 너머 서버에서 도는 작업)은 채팅에서 기억한 것으로 시작하고, Cowork에서 나온 것이 채팅으로 이어진다고 씁니다. 지난 세션에서는 따로 노는 것처럼 보였습니다. 확인 전까지는 "필요한 내용은 Cowork 작업 문장에 직접 적어 주는 게 안전하다"고 답합니다.
장표: 19번, 부록 질문 1.

### 2. "네가 다 알아서 해줘"로 컴퓨터를 통째로 맡겨도 되나요? (보안·개인정보)
권하지 않습니다. 이번 일에 필요한 폴더 하나만 연결하세요. 파일을 영구 삭제하기 전에는 Claude가 허락을 구하지만, 결제·비밀번호·고객 개인정보는 처음부터 맡기지 않는 게 원칙입니다.
장표: 18번, 부록 질문 2.

### 3. 채팅 여러 개를 동시에 돌릴 수 있나요? (병렬 작업: 여러 일을 한꺼번에 나란히 하기)
공식 문서는 큰 일을 작은 일로 나눠 나란히 처리한다고 씁니다. 작업 여러 개를 동시에 띄우는 것은 [확인 필요]입니다. 동시에 돌릴 때 사용량이 어떻게 줄어드는지도 [확인 필요]이니, 여러 개를 띄우기 전에 사용량을 먼저 보라고 답합니다.
장표: 부록 질문 3.

### 4. 어떤 모델·요금제를 써야 하나요? (비용)
Cowork와 예약 작업은 유료 플랜(Pro, Max, Team, Enterprise)에서 쓸 수 있습니다. 여러 단계 작업은 짧은 질문보다 사용량을 많이 씁니다. 플랜별 한도 수치와 모델 선택은 [확인 필요]이니 특정 플랜을 권하지 말고 "작게 써 보고 판단하세요"라고 답합니다.
장표: 부록 질문 4.

### 5. 레퍼런스 사이트를 못 읽어 올 때는? (도구 한계)
지난 세션에서 사이트를 못 읽어 오는 경우가 있었습니다. 어떤 사이트가 왜 안 되는지는 [확인 필요]이니 원인을 단정하지 말고, 페이지를 PDF로 저장하거나 내용을 복사해 파일로 만들어 맡긴 폴더에 넣어 주라고 안내합니다.
장표: 부록 질문 5.

## 나올 것 같은 질문

### 6. 무료 플랜에서도 되나요?
Cowork와 예약 작업은 유료 플랜(Pro, Max, Team, Enterprise)에서만 쓸 수 있습니다. 무료 플랜인 분은 옆 사람과 짝을 지어 함께 보도록 안내합니다.

### 7. 예약 작업을 걸어 두면 컴퓨터를 켜 둬야 하나요?
예약 작업은 원격으로 실행되어, 컴퓨터가 잠자기 상태이거나 앱이 닫혀 있어도 정해진 시간에 돕니다. 다만 작업에 내 컴퓨터의 파일이나 앱이 필요하면 내 컴퓨터에서만 실행됩니다. 그래서 오늘 실습 2는 웹에서 찾아오는 일로 정했습니다. 내 컴퓨터에서 실행될 때 컴퓨터가 꺼져 있으면 어떻게 되는지는 [확인 필요]입니다.

### 8. 주기는 어떻게 정하나요?
매시간, 매일, 매주, 평일, 수동 중에서 고를 수 있고, 필요할 때 바로 한 번 실행할 수도 있습니다. 처음에는 "매일"이나 "매주"로 걸고, 바로 한 번 실행해 결과가 마음에 드는지 먼저 보라고 권합니다.

### 9. 결과가 틀리면 어떻게 하나요?
처음부터 다시 쓰지 말고 고칠 부분만 다시 말하면 됩니다. 예: "교통비는 따로 묶어 줘", "합계 줄을 맨 아래에 넣어 줘". 숫자가 들어간 결과는 몇 개라도 직접 맞춰 보는 습관을 권합니다. 오늘 샘플은 정답이 있어 실습 페이지의 "확인하는 법"으로 바로 맞춰 볼 수 있습니다.

### 10. 휴대폰에서도 되나요?
공식 문서에는 웹과 휴대폰 앱에서도 쓸 수 있다고 되어 있지만, 오늘은 데스크톱 앱 기준으로만 안내합니다. 휴대폰에서 어디까지 되는지는 [확인 필요]이니 단정하지 않습니다.

### 11. 엑셀이 없는데 결과 파일을 열 수 있나요?
결과 파일 형식은 맡기는 문장에 직접 적으면 됩니다. 예: "엑셀 파일로", "CSV(쉼표로 칸을 나눈 표 파일)로도 저장해 줘". 어떤 형식까지 만들 수 있는지는 [확인 필요]이니, 리허설 때 엑셀과 CSV로 한 번씩 만들어 보고 이 답을 고칩니다.

### 12. 내 파일이 밖으로 나가는 건 아닌가요?
데스크톱에서는 연결한 폴더의 파일을 직접 읽고 쓸 수 있습니다. 결과를 어디에 저장하는지, 그 밖의 데이터 처리 방식은 [확인 필요]이니 단정하지 말고, 민감한 자료는 연결하지 않는 게 가장 확실하다고 답합니다. 공식 도움말 링크를 함께 알려 줍니다.

### 13. 예약 작업을 멈추거나 지우려면?
메뉴 위치와 이름은 [확인 필요]입니다. 리허설 때 앱에서 확인해 이 줄을 고칩니다. 현장에서는 진행자 화면으로 같이 찾아봅니다.

### 14. 오늘 만든 예약 작업이 내일 아침에 안 오면?
다음 날 아침 리마인드 메시지(`comms/post-session.md`)에 확인할 것을 적어 둡니다. 먼저 예약한 시간과 주기가 맞는지, 바로 실행했을 때 결과가 나왔는지를 보라고 안내합니다. 기록을 보는 메뉴 이름은 [확인 필요]입니다.
