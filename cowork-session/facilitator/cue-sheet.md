## 구간별 백업 플랜

**와이파이가 불안정할 때**
- 장표는 인터넷 없이 열린다. 걱정하지 않아도 된다.
- 샘플 zip을 못 받는 사람이 많으면, 진행자 노트북의 `samples/cowork-samples.zip`을 USB 메모리로 돌린다. USB 메모리 1~2개를 미리 준비한다.
- 실습 페이지가 안 열리면 장표 9번·16번의 공식과 뜯어가는 문장을 보고 직접 입력하게 한다.
- 실습 2(웹 검색)가 계속 실패하면, 예약 작업 등록까지만 하고 "바로 실행"은 집에서 해 보게 한다.

**참석자가 사용량 한도에 걸렸을 때**
- 옆 사람과 짝을 지어 한 화면으로 같이 본다.
- 미션 D(회의 녹취, 텍스트 파일 하나)처럼 가벼운 미션으로 바꾼다.
- "여러 단계 작업은 짧은 질문보다 사용량을 더 씁니다"를 이때 한 번 더 말한다. 플랜별 한도 수치는 말하지 않는다 [확인 필요].

**진행자 화면과 참석자 화면이 다를 때**
- Cowork가 Claude 하나로 합쳐지는 중이라(Pro·Max부터 순차 적용) 구버전은 입력창에 Chat·Cowork 선택지가 있고, 새 버전은 없다.
- 새 버전이면 정상이다. 선택지를 찾지 말고 그냥 Claude에게 맡기는 문장을 보내게 한다.
- 리허설 때 찍어 둔 구버전·새 버전 화면 캡처를 띄워 "이 중 하나면 맞습니다"라고 보여 준다.

**Cowork가 안 보일 때 (구버전 화면인데 선택지가 없을 때)**
- 먼저 유료 플랜(Pro, Max, Team, Enterprise)으로 로그인했는지 본다.
- Claude 데스크톱 앱이 최신인지 본다. Windows는 최신 앱이 꼭 필요하다 (claude.com/download).
- 그래도 안 되면 옆 사람 화면으로 같이 하고, 문제 해결 문서(`troubleshooting.md`)의 해당 항목을 쉬는 시간에 본다.

**시연이 오래 걸릴 때**
- 시연 1은 2분 넘게 기다리지 않는다. 리허설 때 찍어 둔 결과 캡처(8번 장표)로 넘어가고, 실제 결과는 실습 시간에 다시 확인한다.
- 시연 2는 "바로 실행" 결과를 기다리지 않고 예약 등록 화면까지만 보여 준 뒤 16번으로 넘어간다.

**시간이 모자랄 때 줄일 곳 (앞에서부터)**
1. 4번 질문을 두 명에서 한 명으로 (2분)
2. 6번을 한 문장으로 (1분)
3. 실습 1을 22분에서 18분으로 (4분). 이때 미션은 A나 D만 권한다.
4. 19번 현실 팁을 사용량 한 줄만 (3분)
5. 그래도 모자라면 실습 2는 등록까지만 하고 바로 실행은 집에서

**시간이 남을 때**
- 부록 장표의 질문을 하나씩 연다.
- 실습 1을 끝낸 사람에게 두 번째 미션을 권한다.
