# 현장 문제 해결

진행자용. 증상 → 원인 추정 → 현장 대처 순서로 적었다. 원인은 추정이니 참석자에게 단정해서 말하지 않는다.
메뉴나 버튼 이름은 확인되지 않은 것이 많다. 그런 곳은 `[확인 필요]`로 두고 진행자 화면을 보며 같이 찾는다.

## 시작할 때

### Cowork가 안 보인다
- **원인 추정:** 무료 플랜으로 로그인했다. 앱이 예전 버전이다(Windows는 최신 앱이 꼭 필요하다). 여는 위치를 못 찾았다(공지에는 "Cowork 탭", 공식 문서에는 "메시지 입력창에서 Cowork 선택"이라고 되어 있다) [확인 필요].
- **현장 대처:** 유료 플랜(Pro, Max, Team, Enterprise)인지 먼저 본다. 앱을 최신 버전으로 바꾼다(Windows는 claude.com/download에서 받기). 그래도 안 되면 옆 사람과 짝을 지어 진행하고, 쉬는 시간에 다시 본다.

### 샘플 zip을 받을 수 없다
- **원인 추정:** 휴대폰으로 받았다. 와이파이가 느리다. 회사 노트북이라 다운로드가 막혀 있다.
- **현장 대처:** 노트북에서 실습 페이지를 다시 열어 받게 한다. 안 되면 진행자의 USB 메모리로 `cowork-samples.zip`을 돌린다.

### zip을 풀었더니 한글 파일 이름이 깨진다
- **원인 추정:** 압축 프로그램이 파일 이름의 글자 방식(UTF-8 표시)을 읽지 못했다. 샘플 zip은 UTF-8 표시를 넣어 만들었고 `tools/verify_samples.py`로 확인했다.
- **현장 대처:** Windows 기본 "압축 풀기"로 다시 풀어 본다. 그래도 깨지면 파일 이름이 깨진 채로 진행해도 미션은 할 수 있다(Cowork가 파일을 열어 내용을 읽는다). 리허설 때 Windows 노트북으로 한 번 확인해 둔다.

## 실습 1 (폴더 맡기기)

### 폴더 접근을 허락하라는 창이 뜬다
- **원인 추정:** Cowork가 폴더를 읽거나 쓰기 전에 묻는 것으로 보인다 [확인 필요: 권한 창의 동작].
- **현장 대처:** 창이 뜨면 먼저 어떤 폴더를 묻는지 읽게 한다. 오늘 맡길 샘플 폴더가 맞을 때만 허락하게 한다. 창의 문구, 버튼 이름, 폴더 단위로 고를 수 있는지는 [확인 필요]이니 리허설 때 확인해 이 항목을 고친다.

### 결과 파일이 어디 있는지 못 찾는다
- **원인 추정:** 결과가 맡긴 폴더 안이나 다른 위치에 저장됐다.
- **현장 대처:** 같은 대화에 "만든 파일이 어디 있는지 알려 줘"라고 묻게 한다. 다음부터는 문장 끝에 "결과는 이 폴더 안에 저장해 줘"를 붙이게 한다.

### 작업이 멈춘 것처럼 보인다
- **원인 추정:** 여러 단계 작업이라 시간이 걸린다. 사진이 많거나 파일을 하나씩 여는 중이다. 허락을 묻는 창이 다른 창 뒤에 가려졌을 수도 있다 [확인 필요].
- **현장 대처:** 리허설 때 잰 시간(리허설 체크 참고)만큼은 기다린다. 화면에 허락을 묻는 창이 없는지 본다. 그래도 안 움직이면 미션 D(텍스트 파일 하나)처럼 가벼운 미션으로 바꾼다.

### 결과 숫자가 정답과 다르다
- **원인 추정:** 흐릿한 사진을 잘못 읽었다. 중복 영수증을 두 번 셌다. 견적서 각주를 빠뜨렸다.
- **현장 대처:** `answer-keys.md`의 "놓치기 쉬운" 항목을 보고, 고칠 부분만 다시 말하게 한다. 예: "같은 영수증이 두 번 들어갔는지 다시 확인해 줘", "각주에 있는 유지보수 비용도 넣어 줘". 틀린 것을 찾아 고치는 것도 실습이라고 말해 준다.

### 파일을 지우려고 한다
- **원인 추정:** "정리해 줘"를 지우라는 뜻으로 받아들였다.
- **현장 대처:** 영구 삭제 전에는 Claude가 허락을 구한다. 허락하지 말고 "아무것도 지우지 말고 옮기기만 해 줘"라고 다시 말하게 한다. 미션 B 문장에는 이미 이 말이 들어 있다.

## 실습 2 (예약 작업)

### 예약 작업 메뉴를 못 찾는다
- **원인 추정:** 메뉴 위치를 모른다. 공식 문서 기준 영어 이름은 왼쪽 사이드바 "Scheduled"와 "New task"다. 한국어 화면 이름은 [확인 필요].
- **현장 대처:** 진행자 화면(장표 15번 시연)을 다시 보여 주고 같은 순서로 따라 하게 한다.

### 바로 실행했는데 결과가 이상하거나 비어 있다
- **원인 추정:** `[대괄호]` 부분을 안 바꿨다. 찾을 주제가 너무 넓거나 좁다. 웹에서 못 읽는 사이트만 있다.
- **현장 대처:** 대괄호를 자기 업종이나 키워드로 바꿨는지 본다. "무엇은 빼고"를 한 줄 더 넣게 한다. 결과가 마음에 들 때까지 문장을 고친 뒤 등록하게 한다.

### 사용량 한도에 걸렸다
- **원인 추정:** 실습 1에서 큰 작업을 여러 번 돌렸다. 플랜별 한도 수치는 [확인 필요].
- **현장 대처:** 옆 사람 화면으로 같이 본다. 집에 가서 다시 해 보도록 실습 페이지 주소를 알려 준다.

### 메일·캘린더를 연결하고 싶어 한다
- **원인 추정:** 연결된 도구(커넥터)를 써 보고 싶다.
- **현장 대처:** 개인정보 부담이 있어 오늘은 선택 미션으로만 안내한다. 연결 방법과 메뉴는 [확인 필요]라 현장에서 단계별로 안내하지 않는다.

## 실습 페이지

### 복사하기 버튼이 안 된다
- **원인 추정:** 브라우저가 복사를 막았다. 페이지는 실패하면 "복사가 안 됐어요. 문장을 길게 눌러 직접 복사하세요"라고 보여 준다.
- **현장 대처:** 문장을 길게 누르거나 끌어서 직접 복사하게 한다. 노트북에서 페이지를 열어 복사하면 붙여 넣기가 더 쉽다.

### QR이 안 찍힌다
- **원인 추정:** 화면이 멀거나 반사된다. 주소가 아직 비어 있다(`[주소 진행자 기입]`).
- **현장 대처:** 주소를 말로 불러 주거나 모임 채팅방에 올린다. 리허설 때 휴대폰으로 미리 찍어 본다.

## 다음 날

### 예약한 결과가 아침에 안 왔다
- **원인 추정:** 예약 시간이나 주기를 잘못 골랐다. 작업이 내 컴퓨터 파일을 필요로 해서 내 컴퓨터에서만 실행되게 됐다. 사용량 한도에 걸렸다.
- **현장 대처(메시지로):** 예약한 시간과 주기를 다시 보고, 바로 한 번 실행해 결과가 나오는지 보라고 안내한다. 실행 기록을 보는 메뉴 이름은 [확인 필요].
