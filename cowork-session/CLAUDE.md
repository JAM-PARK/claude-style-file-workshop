# Cowork 입문 세션 준비 자료: 이 폴더의 규칙

세션 "퇴근 후에도 일하는 AI 직원 만들기: 클로드에게 내 일 통째로 맡기기"의 장표, 샘플, 실습 페이지, 진행자 문서, 안내 메시지를 만든다.
전체 명세는 `HANDOFF.md`(로컬 전용)이고, 제품 사실과 확정한 결정은 `PRODUCT.md`에 있다. 둘이 다르면 `PRODUCT.md`의 확정 결정을 따른다.

## 작업 규칙
- 모든 텍스트는 한국어. 참석자는 개발 경험이 없으므로 전문 용어는 처음 나올 때 한 줄로 풀어 쓴다.
- 친근하되 과장 없이. "혁신적인", "놀라운" 같은 수식어를 쓰지 않는다. 장표·페이지 본문에 이모지를 쓰지 않는다.
- 제품 사실은 `PRODUCT.md`의 "확인한 사실" 범위 안에서만 쓴다. 메뉴 이름, 버튼 이름, 플랜별 한도 수치는 지어내지 않고 `[확인 필요]`로 표시한다.
- 인물·회사·상호·연락처·사업자번호는 모두 가상으로, 가짜임이 분명한 형식으로 만든다 (010-0000-1234, 000-00-00000). 실존 브랜드를 쓰지 않는다.
- 진행자가 채울 값은 `[진행자 기입]`으로 남긴다.

## 디자인
장표, 실습 페이지, 치트시트는 `DESIGN.md` 한 장을 따른다 (가게 유리문에 붙인 A4 안내문).
방향 계약은 `.impeccable/surfaces/slides-index-html.md`에 있다. 새 화면을 만들거나 크게 바꿀 때는 impeccable 스킬 절차(검수와 DESIGN.md 갱신까지)를 따른다.
- `DESIGN.md`에 없는 색이나 부품이 필요하면 코드에 바로 넣지 않고 `DESIGN.md`부터 고친다.
- 금지(HANDOFF 5-1): 파랑·남색·보라 메인 컬러, 보라→파랑 그라디언트, 둥근 카드와 그림자, 이모지 아이콘.

## 기술
- 산출물마다 단일 HTML 파일. CSS·JS 인라인, 외부 빌드 없음.
- 장표는 인터넷 없이 열린다. 폰트는 `tools/build.py`가 쓰인 글자만 잘라 base64로 넣는다. 장표 글을 고친 뒤에는 다시 빌드한다.
- 실습 페이지는 Google Fonts 링크를 쓰되 대체 폰트를 지정한다. Vercel에 배포한다.
- 보조 스크립트는 `tools/`, 파이썬 의존성은 `tools/.venv`에 둔다.
