# 결과물 가져가기

claude.ai에서 만든 결과물은 대화 안에 있습니다. 밖에서 쓰려면 먼저 HTML 파일로 저장합니다. 이 순서는 **노트북 브라우저에서** 이 페이지(session02-handout.vercel.app)를 열어 따라 하세요. 휴대폰에서 받으면 파일이 휴대폰에 저장됩니다.

**claude.ai 공유 링크는 손님에게 보낼 링크로 쓰기 어렵습니다.** 2026년 9월 16일 이후 새로 만든 결과물은 무료 계정에서 링크로 공유할 수 없고, 유료 계정이라도 링크를 여는 사람에게 Claude 계정이 있어야 합니다(2026-09-30 확인).

## 1. HTML 파일로 저장하기

1. 결과물 창에 다운로드 버튼이 보이면 그걸로 받고 2단계로 갑니다. 없으면 결과물 창에서 코드를 열어 전부 복사합니다.
2. 아래 칸에 붙여 넣고 **index.html로 받기**를 누릅니다. 다운로드 폴더에 `index.html`이 생깁니다.
3. 바탕화면에 새 폴더를 하나 만들고 `index.html`을 그 폴더로 옮깁니다. 아래 순서는 모두 이 폴더로 합니다.

<!-- 배포 페이지에서는 이 자리에 코드를 붙여 넣는 칸이 나옵니다 -->
[[SAVER]]

코드가 `<!doctype html>`이 아니라 `import`로 시작하면 그대로는 열리지 않습니다. 대화에 "HTML 파일 하나로 다시 줘"라고 부탁하세요.

## 2. 내 사진 넣기 (사진이 있으면)

대화 안에서는 내 사진을 보여 줄 수 없어서 사진 자리가 빈 네모로 나옵니다. 저장한 뒤에 채웁니다.

1. 사진을 같은 폴더에 넣고, 사진 자리 순서대로 이름을 `photo1.jpg`, `photo2.jpg`처럼 바꿉니다. .png 사진이면 `photo1.png`처럼 두고 아래 문장의 이름도 바꿉니다. 아이폰 사진(.heic)은 브라우저에 보이지 않으니 JPG로 바꿔서 넣습니다(Mac은 미리보기의 파일 > 내보내기).
2. 결과물을 만든 대화에 아래 문장을 보냅니다.

```
사진 자리를 위에서부터 순서대로 photo1.jpg, photo2.jpg … 파일을 보여 주는 <img>로 바꿔줘. 사진은 자리 너비에 맞추고 넘치는 부분은 잘라줘. 전체 코드를 다시 줘.
```

새로 받은 코드를 1번처럼 `index.html`로 받아 폴더의 옛 파일을 바꿔 넣습니다. 폴더에서 `index.html`을 열면 사진이 보입니다.

## 3. 소개용 웹페이지: 링크 만들기

Netlify Drop을 쓰면 계정 없이도 끌어다 놓기만으로 주소가 생깁니다.

1. [app.netlify.com/drop](https://app.netlify.com/drop)을 열고 `index.html`이 든 폴더를 화면에 끌어다 놓습니다. 사진도 함께 올라갑니다.
2. 생긴 주소를 휴대폰에서 열어 봅니다.

계정 없이 올린 사이트가 언제까지 남는지는 공식 문서에 없습니다. 오래 쓸 주소라면 무료 계정으로 로그인한 뒤 올리세요.

## 4. 상세페이지: 긴 이미지로 만들기

네이버 스마트스토어 상세설명 권장 너비는 가로 860px이고 이미지 한 장은 20MB까지입니다. 휴대폰에서는 HTML이 미리보기 그림으로만 보이므로 이미지로 올리는 편이 안전합니다(2026-09-30 확인).

Chrome에서 폴더의 `index.html`을 열고 아래 순서대로 합니다. 설치할 것은 없습니다.

1. 개발자 도구를 엽니다. Mac은 `Cmd+Option+I`, Windows는 `F12`
2. 기기 모드로 바꿉니다. Mac은 `Cmd+Shift+M`, Windows는 `Ctrl+Shift+M`
3. 화면 위쪽 너비 칸에 `860`을 넣습니다.
4. 명령 창을 엽니다. Mac은 `Cmd+Shift+P`, Windows는 `Ctrl+Shift+P`
5. `screenshot`(한국어 화면이면 `스크린샷`)을 입력하고 **Capture full size screenshot**(전체 크기 스크린샷)을 고릅니다. 다운로드 폴더에 PNG가 생깁니다.

- 이미지 가로가 1720px로 나오면 화면이 고해상도라 두 배로 찍힌 것입니다. 기기 모드 위쪽 줄 오른쪽 끝의 점 세 개 메뉴에서 **Add device pixel ratio**를 켜고 `1`을 고른 뒤 다시 찍습니다.
- 대화 화면을 그대로 캡처하면 대화창까지 찍힙니다. 꼭 저장한 `index.html`을 열어서 찍으세요.
- 스마트스토어는 상세가 4000px을 넘으면 위 3000px만 먼저 보이고 나머지는 접힙니다. 핵심 문구와 특징을 위쪽에 둡니다.
- 쿠팡은 WING 등록 화면에 뜨는 크기 안내를, 와디즈는 가로 1024px 이하를 따릅니다.
- 상품정보제공고시는 상세 이미지와 별도로 등록 화면에서 입력하는 필수 항목입니다.
