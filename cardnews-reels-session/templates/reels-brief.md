# 릴스 장면 계획표

실습 4에서 애니메이션을 만들기 전에 채우는 표예요. 다 채우면 실습 4 프롬프트의 [대괄호]에 옮겨 적어요.

비율과 길이는 처음에 정해요. 나중에 바꾸면 처음부터 다시 만들어야 해요.

## 빈칸

| 항목 | 채울 내용 |
|---|---|
| 목적 | [예: 신메뉴 알리기] |
| 보는 사람 | [주요 고객] |
| 길이·비율 | 15초, 세로 9:16 |
| 장면 1 (0~3초) | 훅 문구(스크롤을 멈추게 하는 첫 문구): [문구] |
| 장면 2 (3~10초) | 사진 1장과 특징 2개: [특징 1], [특징 2] |
| 장면 3 (10~15초) | 로고와 행동 요청: [행동 요청 문구] |
| 쓸 자료 | [로고 파일 이름], [사진 파일 이름] |
| 하지 말 것 | 지어낸 숫자나 효과, 재생 화면 안의 버튼이나 다른 글자 |

## 예시: 골목 한그릇(가상 브랜드)

| 항목 | 채운 내용 |
|---|---|
| 목적 | 근처 직장인에게 점심 메뉴로 알리기 |
| 보는 사람 | 근처 회사에 다니는 30~50대 직장인 |
| 길이·비율 | 15초, 세로 9:16 |
| 장면 1 (0~3초) | 훅 문구: "오늘 점심, 국밥 한 그릇 어때요?" |
| 장면 2 (3~10초) | 국밥 사진과 특징 2개: "아침마다 가게에서 끓이는 국물", "혼자 와도 편한 자리" |
| 장면 3 (10~15초) | 로고와 행동 요청: "점심 메뉴 고민될 때 저장해 두세요" |
| 쓸 자료 | golmok-logo.png, golmok-gukbap.png (실습용 로고·사진 묶음) |
| 하지 말 것 | 지어낸 숫자나 효과, 재생 화면 안의 버튼이나 다른 글자 |

## 다 채웠으면

1. 실습 4 프롬프트를 복사해요.
2. [주요 고객], [문구], [행동 요청 문구]를 이 표의 내용으로 바꿔요.
3. 프롬프트 맨 아래에 특징 2개를 한 줄로 적어요.
   예: 특징은 "아침마다 가게에서 끓이는 국물", "혼자 와도 편한 자리"예요.
4. 로고와 사진을 첨부해서 보내요.
