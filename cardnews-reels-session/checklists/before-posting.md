# 업로드 전 체크리스트

카드 뉴스나 릴스를 올리기 전에 하나씩 확인해요. Claude가 검수했더라도 마지막 판단은 사람이 해요.

## 카드 뉴스 규격

- [ ] 모든 장이 1080×1350(세로 4:5)으로 같은 비율인가요?
- [ ] 6~10장인가요? (실습 지침 예시는 6~8장)
- [ ] 1장에 훅(스크롤을 멈추게 하는 첫 문구)이 있나요?
- [ ] 마지막 장에 행동 요청(저장, 공유 등)이 하나만 있나요?
- [ ] 한 장에 한 가지 이야기만 하나요?

규격과 장수는 업계 가이드 기준이에요(2026년 10월). 올리기 전에 다시 확인해요.

## 릴스

- [ ] 세로 9:16인가요?
- [ ] 화면 녹화한 영상 안에 재생 버튼이나 다른 글자가 보이지 않나요?
- [ ] 영상 속 로고와 글자가 뭉개지지 않았나요?

## 화장품 광고 표현

- [ ] 의약품으로 오해할 표현이 없나요? (예: 소염, 염증 완화, 피부 재생)
- [ ] 질환명이나 의학적 효능이 없나요? (예: 아토피, 건선, 항염)
- [ ] 절대적 표현이 없나요? (예: 최고, 최상)
- [ ] "無첨가", "OO-free" 같은 표현은 근거를 확인했나요?
- [ ] 전문가가 추천한 것처럼 보이는 표현이 없나요?

위 목록은 예시예요. 실제 광고 전에는 식약처 기준으로 확인해요.

## 식당·음식 광고 표현

- [ ] 근거 없는 "최고", "1등" 같은 표현이 없나요?
- [ ] 직접 확인하지 않은 숫자가 없나요?

식품 광고 규정은 별도 확인이 필요해요.

## 모든 업종 공통

- [ ] 근거 없는 숫자나 효과를 지어내지 않았나요?
- [ ] 가격, 영업시간, 위치 같은 정보가 지금과 같나요?

## AI로 만든 이미지와 영상

- [ ] AI로 만든 가상 인물이 제품을 추천한다면 "가상인물"이라고 표시했나요?
- [ ] 실제 사진처럼 보이는 AI 이미지에는 "AI로 만든 이미지"라고 표시했나요? (권장)

AI 가상 인물 표시는 2026년 6월 1일부터 적용된 공정위 심사지침이라는 업계 해석이 있어요. 법적 표시 의무는 원칙적으로 AI 사업자에게 있고 광고주는 대상이 아니라는 해석이지만, 스스로 표시하는 게 안전해요.
