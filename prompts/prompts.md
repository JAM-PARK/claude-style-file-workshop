# 시작 프롬프트와 보조 프롬프트

기본 트랙 기준입니다. 이 문장들은 **스타일 파일을 프로젝트에 설정해 둔 상태에서** 씁니다. 파일을 매번 붙이지 않는다는 점이 핵심입니다.
`[ ]` 안은 내 내용으로 바꿔 넣으세요.

| 공지의 결과물 | 쓰는 프롬프트 |
| --- | --- |
| 발표·제안용 슬라이드 | 시작 1 |
| 소개용 웹페이지 | 시작 2 |
| 상품·서비스 상세페이지 | 시작 3 |
| 사내 문서·보고서 | 시작 4 |
| 실습① 스타일 파일 초안 | 보조 1 |
| 실습③ 어긋난 결과 점검 (14번 슬라이드) | 보조 2 |
| 실습① 참고 자료 없이 질문에 답하며 만들기 | 보조 3 |

## 시작 1. 발표·제안용 슬라이드

```
프로젝트에 올려둔 디자인 시스템을 따라 [주제] 발표 슬라이드 3장을 만들어줘.
1장 제목, 2장 핵심 내용 3가지, 3장 다음 할 일.
디자인 시스템에 없는 색, 폰트, 그림자, 그라디언트는 쓰지 마.
```

## 시작 2. 소개용 웹페이지

다 만든 뒤 링크로 가져가는 방법은 배포 페이지의 **결과물 가져가기**에 있습니다.

```
프로젝트에 올려둔 디자인 시스템을 따라 [나 / 우리 가게 / 서비스] 소개 웹페이지 한 장을 HTML 파일 하나로 만들어줘.
들어갈 내용: 한 줄 소개, 하는 일 3가지, 연락 방법.
내용 메모: [소개 문구, 하는 일, 연락처를 적어 넣기]
레이아웃은 디자인 시스템의 '레이아웃' 칸을 따르고, '쓰지 말 것'에 있는 건 하나도 쓰지 마.
사진이 들어갈 곳은 테두리만 있는 빈 네모에 '사진: 무엇'이라고 적어 둬.
내가 적지 않은 연락처, 주소, 수치는 지어내지 말고 [ ]로 비워 둬.
```

## 시작 3. 상품·서비스 상세페이지

스마트스토어 권장 너비(가로 860px)에 맞춥니다. 다 만든 뒤 긴 이미지로 가져가는 방법은 배포 페이지의 **결과물 가져가기**에 있습니다.

```
프로젝트에 올려둔 디자인 시스템을 따라 [상품·서비스 이름] 상세페이지를 가로 860px, 세로로 긴 한 장의 HTML 파일 하나로 만들어줘.
순서: 핵심 문구, 특징 3개, 사용 장면, 스펙 표, 구매 안내. 핵심 문구와 특징은 맨 위 3000px 안에 넣어줘.
상품 정보: [가격, 크기·용량, 구성, 배송, 특징 메모를 적어 넣기]
사진이 들어갈 곳은 테두리만 있는 빈 네모에 '사진: 무엇'이라고 적어 둬.
후기, 별점, 판매량, 인증, 수치는 지어내지 말고 내가 적은 것만 써. 모르는 칸은 [ ]로 비워 둬.
디자인 시스템에 없는 요소는 추가하지 말고, 화면에 붙어 따라다니는 메뉴나 버튼은 쓰지 마.
```

## 시작 4. 사내 문서·보고서

```
프로젝트에 올려둔 디자인 시스템을 따라 [주간 보고 / 회의록 / 기획서] 서식을 만들어줘.
구성: 제목, 요약 3줄, 표 1개, 다음 할 일.
A4 한 장에 인쇄되게 해줘.
```

## 보조 1. 참고 자료로 스타일 파일 초안 만들기

실습①에서 준비물(참고 자료)을 가져온 분이 씁니다.

```
첨부한 자료의 스타일을 보고 아래 디자인 시스템 템플릿의 칸을 채워줘.
자료에서 확실히 보이는 값만 채우고, 추측한 값에는 (추측)이라고 표시해줘.
'쓰지 말 것' 칸은 이 자료에 없는 흔한 AI 스타일 위주로 채워줘.

[템플릿 붙여넣기]
```

## 보조 2. 어긋난 결과 점검하기

실습③에서 결과물이 마음에 안 들 때, 다시 생성하기 전에 씁니다 (14번 슬라이드).

```
방금 만든 결과물이 디자인 시스템을 어긴 곳이 있는지 칸별로 점검해줘.
어긴 곳이 있으면 결과물을 고치지 말고, 디자인 시스템 문서의 어느 칸이 비어 있거나 모호해서 그렇게 됐는지 먼저 알려줘.
```

## 보조 3. 질문에 답하며 스타일 파일 만들기

참고 자료가 없거나 디자인이 막막한 분이 실습①에서 씁니다. Claude가 보기를 주며 하나씩 묻습니다.

```
나는 디자인을 잘 몰라. 아래 디자인 시스템 템플릿을 질문에 답하면서 같이 채우고 싶어.
질문은 한 번에 하나씩, 고를 수 있는 보기 3개와 함께 해줘. 질문은 모두 7개 이내로.
답을 다 받으면 템플릿의 모든 칸을 채워줘. 폰트는 Google Fonts에 있는 한글 폰트 이름으로, 색은 #으로 시작하는 값으로.
'쓰지 말 것'은 흔한 AI 스타일(보라 그라디언트, 똑같은 카드 3개, 이모지 아이콘 등) 가운데 내 답과 맞지 않는 것으로 4줄 이상 채워줘.

[템플릿 붙여넣기]
```
